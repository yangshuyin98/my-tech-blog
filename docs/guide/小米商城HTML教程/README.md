# 小米商城前端实战 - 分阶段实施指南

> 技术栈：HTML5、CSS3、JavaScript（原生）
> 架构：纯前端静态页面，无后端依赖
> 参考站点：https://www.mi.com/shop

## 项目简介

本教程带你使用 HTML + CSS + JS 从零仿写小米商城首页。所有 class 命名和页面结构均参照真实小米商城网站，确保学到的技能可以直接应用到实际项目中。通过这个实战项目，你将掌握页面布局、CSS 动画、事件处理等前端核心技能。

- 了解 CSS 基础选择器和属性
- 了解 JavaScript 基础语法
- 安装了 VS Code 或 WebStorm 编辑器

## 核心概念

### 1. Container 居中布局

小米商城所有内容都限制在 1226px 宽度的容器内，通过 `margin: 0 auto` 实现水平居中。这是整个页面的布局基础，每个区域（顶部通栏、导航、Banner、商品区域、底部）都复用同一个 `.container` 类。

```css
.container {
    width: 1226px;
    margin: 0 auto;
    position: relative;   /* 为内部绝对定位元素建立参照 */
}
```

布局示意：

```
|<──────────────── 全屏宽度 ────────────────>|
|     |<──── 1226px .container ────>|       |
|     |  所有内容都在这里居中显示    |       |
```

### 2. 绝对定位叠加 (Absolute Positioning)

Banner 区域的核心技巧是：侧边栏（`.site-category`）用绝对定位覆盖在轮播图（`.swiper-container`）上方。父元素 `.home-hero` 设置 `position: relative` 作为定位参照。

```css
.home-hero {
    position: relative;    /* 建立定位上下文 */
}

.site-category {
    position: absolute;    /* 脱离文档流，盖在轮播图上 */
    left: 0;
    top: 0;
    width: 234px;
    height: 460px;
    z-index: 5;            /* 确保在轮播图上方 */
}

.swiper-container {
    width: 1226px;
    height: 460px;
}
```

布局示意：

```
|<───────────── 1226px .home-hero ─────────────>|
| position: relative                             |
| ┌──────────┬─────────────────────────────────┐|
| │site-     │  swiper-container               │|
| │category  │  (轮播图，宽度占满)              │|
| │(234px)   │                                 │|
| │绝对定位  │                                 │|
| │盖在上面  │                                 │|
| └──────────┴─────────────────────────────────┘|
```

### 3. CSS Hover 控制二级菜单

侧边栏的二级菜单默认隐藏，鼠标悬停在一级菜单项上时才显示。这是纯 CSS 实现的交互，不需要 JavaScript。

```css
/* 二级菜单默认隐藏 */
.category-item .children {
    display: none;
    position: absolute;
    left: 234px;           /* 紧贴侧边栏右侧 */
    top: 0;
    width: 992px;
    height: 460px;
    background: #fff;
    z-index: 20;
}

/* 鼠标悬停时显示 */
.category-item:hover .children {
    display: block;
}
```

布局示意：

```
|<── 234px ──>|<─────────── 992px ────────────>|
|              |                                |
| category-    |  children (二级菜单)           |
| item         |  ┌──────────────────────────┐  |
| .title       |  │ [商品图片] [商品图片]     │  |
| [手机]  ─────┼─→│ [商品图片] [商品图片]     │  |
| [电视]       |  │ [商品图片] [商品图片]     │  |
| [笔记本]    |  └──────────────────────────┘  |
|  ...         |  (hover 时才显示)              |
```

### 4. 浮动与清除浮动

导航栏中的多个元素需要水平排列，使用浮动实现。父元素需要清除浮动以撑开高度。

```css
.header-nav {
    float: left;
}

.header-search {
    float: right;
}

/* 清除浮动的几种方式 */
.clearfix::after {
    content: "";
    display: block;
    clear: both;
}

/* 或者使用 overflow */
.container {
    overflow: hidden;
}
```

### 5. 固定定位工具栏

右侧工具栏使用 `position: fixed` 固定在浏览器窗口右侧，不随页面滚动而移动。

```css
.right-tools {
    position: fixed;
    right: 0;
    bottom: 70px;
    z-index: 100;
}
```

## 常见问题

**Q: 页面有空白边距？**
A: body 有默认的 margin（通常 8px），在 reset.css 中用 `* { margin: 0; padding: 0; }` 或更精确的选择器重置。

**Q: 浮动后父元素高度消失了？**
A: 子元素浮动会导致父元素高度坍塌。给父元素添加 `overflow: hidden` 或使用 clearfix 清除浮动。

**Q: 侧边栏二级菜单位置不对？**
A: 确认父元素 `.category-item` 设置了 `position: relative`，子元素 `.children` 的 `left` 值应等于侧边栏宽度（234px）。

**Q: 轮播图没有显示？**
A: 检查 Swiper.js 是否正确引入，确认 `.swiper-container` 设置了固定宽高，检查图片路径是否正确。

**Q: 定位后元素位置不对？**
A: 绝对定位的元素会相对于最近的 `position: relative` 祖先元素定位。检查父元素链上是否有正确的定位设置。

**Q: 客服电话是多少？**
A: 小米商城客服电话为 950816 和 950818。
