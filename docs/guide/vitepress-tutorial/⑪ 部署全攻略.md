## 构建产物

所有平台部署的基础——先构建：

```bash
pnpm docs:build
```

产物在 `docs/.vitepress/dist/` 目录：

```
docs/.vitepress/dist/
├── index.html
├── guide/
│   └── index.html
├── assets/
│   ├── style.xxxxx.css
│   └── index.xxxxx.js
└── ...
```

### base 路径配置

部署到子路径时需要配置 `base`：

```ts
// config.ts
export default defineConfig({
  // 部署到 https://username.github.io/repo-name/
  base: '/repo-name/',

  // 部署到根域名 https://example.com/
  // base: '/',   // 默认值，可省略
})
```

## GitHub Pages

最常用、完全免费的方案。

### 方式一：GitHub Actions（推荐）

创建 `.github/workflows/deploy.yml`：

```yaml
name: Deploy to GitHub Pages

on:
  push:
    branches: [main]

# 设置 GITHUB_TOKEN 权限
permissions:
  contents: read
  pages: write
  id-token: write

# 同一时间只允许一个部署
concurrency:
  group: pages
  cancel-in-progress: false

jobs:
  # 构建
  build:
    runs-on: ubuntu-latest
    steps:
      - name: Checkout
        uses: actions/checkout@v4
        with:
          fetch-depth: 0

      - name: Setup pnpm
        uses: pnpm/action-setup@v4
        with:
          version: 9

      - name: Setup Node.js
        uses: actions/setup-node@v4
        with:
          node-version: 20
          cache: pnpm

      - name: Install dependencies
        run: pnpm install

      - name: Build VitePress
        run: pnpm docs:build

      - name: Upload artifact
        uses: actions/upload-pages-artifact@v3
        with:
          path: docs/.vitepress/dist

  # 部署
  deploy:
    needs: build
    runs-on: ubuntu-latest
    environment:
      name: github-pages
      url: ${{ steps.deployment.outputs.page_url }}
    steps:
      - name: Deploy to GitHub Pages
        id: deployment
        uses: actions/deploy-pages@v4
```

### 配置步骤

```
1. 推送代码到 GitHub
2. 仓库 → Settings → Pages
3. Source → 选择 "GitHub Actions"
4. 推送后自动构建部署
```

### 方式二：gh-pages 分支

```bash
# 安装 gh-pages
pnpm add -D gh-pages

# package.json 添加脚本
# "deploy": "pnpm docs:build && gh-pages -d docs/.vitepress/dist"

pnpm deploy
```

然后在 Settings → Pages → Source 选择 `gh-pages` 分支。

## Vercel

零配置，推送即部署，速度最快。

### 配置步骤

```
1. 登录 vercel.com
2. Import Git Repository → 选择你的仓库
3. Framework Preset → VitePress（通常自动识别）
4. Build Command → pnpm docs:build
5. Output Directory → docs/.vitepress/dist
6. Deploy
```

### vercel.json（可选）

```json
{
  "buildCommand": "pnpm docs:build",
  "outputDirectory": "docs/.vitepress/dist",
  "installCommand": "pnpm install"
}
```

### 特点

| 项目 | 说明 |
|------|------|
| 价格 | 免费额度充足（个人项目够用） |
| 速度 | 全球 CDN，构建极快 |
| 域名 | 自动分配 `.vercel.app` 域名 |
| HTTPS | 自动开启 |
| 预览部署 | 每个 PR 自动生成预览链接 |

## Netlify

免费额度大，适合团队项目。

### 配置步骤

```
1. 登录 app.netlify.com
2. Add new site → Import an existing project
3. 选择 GitHub 仓库
4. Build command → pnpm docs:build
5. Publish directory → docs/.vitepress/dist
6. Deploy site
```

### netlify.toml（推荐）

在项目根目录创建：

```toml
[build]
  command = "pnpm docs:build"
  publish = "docs/.vitepress/dist"

[build.environment]
  NODE_VERSION = "20"

# 自定义域名重定向
[[redirects]]
  from = "/*"
  to = "/index.html"
  status = 200
```

### 特点

| 项目 | 说明 |
|------|------|
| 价格 | 免费额度 100GB/月 |
| 速度 | 全球 CDN |
| 域名 | 自动分配 `.netlify.app` 域名 |
| HTTPS | 自动开启 |
| 表单 | 内置表单处理 |
| Functions | 支持 Serverless Functions |

## Cloudflare Pages

全球 CDN 最强，国内访问速度好。

### 配置步骤

```
1. 登录 dash.cloudflare.com
2. Workers & Pages → Create
3. Connect to Git → 选择仓库
4. Build settings：
   - Framework preset → VitePress
   - Build command → pnpm docs:build
   - Build output directory → docs/.vitepress/dist
5. Save and Deploy
```

### 特点

| 项目 | 说明 |
|------|------|
| 价格 | 完全免费，无带宽限制 |
| 速度 | 全球 300+ 节点，国内访问最优 |
| 域名 | 自动分配 `.pages.dev` 域名 |
| HTTPS | 自动开启 |
| 国内 | 不被墙，国内访问友好 |

## 自建服务器（Nginx）

适合企业内网、私有部署。

### 构建并上传

```bash
# 本地构建
pnpm docs:build

# 上传到服务器
scp -r docs/.vitepress/dist/* user@server:/var/www/docs/
```

### Nginx 配置

```nginx
server {
    listen 80;
    server_name docs.example.com;

    root /var/www/docs;
    index index.html;

    # SPA 路由回退
    location / {
        try_files $uri $uri/ $uri.html /index.html;
    }

    # 静态资源缓存
    location /assets/ {
        expires 1y;
        add_header Cache-Control "public, immutable";
    }

    # Gzip 压缩
    gzip on;
    gzip_types text/plain text/css application/json application/javascript text/xml;
    gzip_min_length 1000;

    # HTTPS（推荐）
    # listen 443 ssl;
    # ssl_certificate /path/to/cert.pem;
    # ssl_certificate_key /path/to/key.pem;
}
```

### 自动部署脚本

```bash
#!/bin/bash
# deploy.sh

set -e

echo "Building..."
pnpm docs:build

echo "Uploading..."
rsync -avz --delete \
  docs/.vitepress/dist/ \
  user@server:/var/www/docs/

echo "Done! Deployed to docs.example.com"
```

### PM2 进程管理（如果需要 Node 服务）

```bash
# 安装 serve
pnpm add -g serve

# PM2 启动
pm2 start serve --name "docs" -- -s /var/www/docs -l 80

# 保存并开机自启
pm2 save
pm2 startup
```

## 多环境配置

不同环境使用不同配置：

### 环境变量

```ts
// config.ts
import { defineConfig } from 'vitepress'

const isProd = process.env.NODE_ENV === 'production'
const base = process.env.BASE_URL || '/'

export default defineConfig({
  base,
  title: isProd ? 'My Docs' : 'My Docs (Dev)',

  head: isProd
    ? [
        // 生产环境添加分析脚本
        ['script', { async: '', src: 'https://analytics.example.com/script.js' }]
      ]
    : []
})
```

### GitHub Actions 多环境

```yaml
# deploy-staging.yml
name: Deploy to Staging

on:
  push:
    branches: [develop]

jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: pnpm/action-setup@v4
      - uses: actions/setup-node@v4
      - run: pnpm install
      - run: pnpm docs:build
        env:
          BASE_URL: /staging/
      - uses: actions/upload-pages-artifact@v3
        with:
          path: docs/.vitepress/dist
```

### 平台环境变量

```bash
# Vercel / Netlify / Cloudflare 中设置：
# Environment Variables → 添加
BASE_URL=/
NODE_ENV=production
```

## 自定义域名

### GitHub Pages

```
1. 仓库 → Settings → Pages → Custom domain
2. 输入：docs.example.com
3. DNS 设置：
   - CNAME 记录：docs.example.com → username.github.io
4. 勾选 "Enforce HTTPS"
```

### Vercel

```
1. 项目 → Settings → Domains
2. 添加：docs.example.com
3. DNS 设置：
   - CNAME 记录：docs.example.com → cname.vercel-dns.com
```

### Netlify

```
1. 项目 → Domain settings → Add custom domain
2. 输入：docs.example.com
3. DNS 设置：
   - CNAME 记录：docs.example.com → your-site.netlify.app
```

### Cloudflare Pages

```
1. 项目 → Custom domains → Set up a custom domain
2. 输入：docs.example.com
3. DNS 设置（如果用 Cloudflare DNS 自动配置）
```

### CNAME 文件

在 `docs/public/` 目录下创建 `CNAME` 文件：

```
docs.example.com
```

## 平台对比

| 维度 | GitHub Pages | Vercel | Netlify | Cloudflare | 自建 Nginx |
|------|-------------|--------|---------|------------|-----------|
| **价格** | 免费 | 免费额度 | 免费额度 | 完全免费 | 服务器费用 |
| **构建速度** | 中 | 极快 | 快 | 快 | 取决于服务器 |
| **国内访问** | ❌ 被墙 | ⚠️ 不稳定 | ⚠️ 不稳定 | ✅ 好 | ✅ 最好 |
| **HTTPS** | ✅ | ✅ | ✅ | ✅ | 需手动配置 |
| **自定义域名** | ✅ | ✅ | ✅ | ✅ | ✅ |
| **预览部署** | ✅ | ✅ | ✅ | ✅ | ❌ |
| **CDN** | Fastly | 全球 | 全球 | 300+ 节点 | 无 |
| **适合** | 个人项目 | 个人/团队 | 国际项目 | 国内访问 | 企业内网 |

### 选型建议

| 场景 | 推荐 |
|------|------|
| 个人博客、开源项目文档 | **GitHub Pages** |
| 追求速度、频繁部署 | **Vercel** |
| 国内用户为主 | **Cloudflare Pages** |
| 企业内网、私有部署 | **自建 Nginx** |
| 不想折腾 | **Vercel**（零配置） |
