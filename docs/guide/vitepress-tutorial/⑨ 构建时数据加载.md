## 什么是构建时数据加载

VitePress 提供了 **Data Loader** 机制：在**构建时**执行数据加载逻辑，结果序列化为 JSON 打包进客户端。

```
构建时（Node.js）          →  客户端（浏览器）
扫描 .md 文件、读取内容       →  直接使用 JSON 数据
fs / path / 任意 npm 包     →  零运行时开销
```

**核心价值：** 把「运行时扫描」变成「构建时预处理」，页面加载零开销。

### 文件约定

数据加载器文件必须以 `.data.js` 或 `.data.ts` 结尾：

```
docs/
├── .vitepress/
├── posts/
│   ├── posts.data.ts      # 数据加载器
│   ├── hello.md
│   └── world.md
└── index.md
```

## 基础用法

### 最简示例

```ts
// docs/posts/hello.data.ts
export default {
  load() {
    return {
      hello: 'world',
      count: 42
    }
  }
}
```

```markdown
<!-- 在 .md 或 .vue 中使用 -->
<script setup>
import { data } from './hello.data.ts'
</script>

数量：{{ data.count }}
```

### 异步加载

```ts
export default {
  async load() {
    const res = await fetch('https://api.example.com/data')
    return res.json()
  }
}
```

### TypeScript 类型

```ts
import { defineLoader } from 'vitepress'

  title: string
  count: number
}

declare const data: Data
export { data }

export default defineLoader({
  load(): Data {
    return { title: 'Hello', count: 42 }
  }
})
```

## createContentLoader 详解

`createContentLoader` 是 VitePress 内置的工具函数，专门用于扫描 Markdown 文件。

### 基础语法

```ts
// docs/posts/posts.data.ts
import { createContentLoader } from 'vitepress'

export default createContentLoader('posts/*.md')
```

### 返回数据类型

```ts
interface ContentData {
  url: string                    // 页面 URL，如 /posts/hello.html
  frontmatter: Record<string, any>  // frontmatter 数据

  // 以下需要通过选项开启
  src?: string                   // 原始 Markdown 源码
  html?: string                  // 渲染后的 HTML
  excerpt?: string               // 摘要（第一个 --- 之前的内容）
}
```

### 选项配置

```ts
createContentLoader('posts/*.md', {
  // 包含原始 Markdown 源码
  includeSrc: false,

  // 包含渲染后的完整 HTML
  render: false,

  // 包含摘要（第一个 --- 之前的内容，渲染为 HTML）
  excerpt: false,

  // 数据转换（排序、过滤、映射）
  transform(rawData) {
    return rawData
      .sort((a, b) => +new Date(b.frontmatter.date) - +new Date(a.frontmatter.date))
      .map(item => ({
        title: item.frontmatter.title,
        date: item.frontmatter.date,
        url: item.url,
      }))
  }
})
```

### glob 模式

```ts
// 匹配所有 .md
createContentLoader('*.md')

// 匹配子目录
createContentLoader('posts/*.md')

// 匹配多级目录
createContentLoader('**/*.md')

// 匹配特定目录
createContentLoader('{posts,articles}/*.md')

// 排除特定文件
createContentLoader('posts/*.md')  // 自动跳过非 .md 文件
```

## 实战：文章列表页

### 数据加载器

```ts
// docs/posts/posts.data.ts
import { createContentLoader } from 'vitepress'

interface Post {
  title: string
  url: string
  date: string
  dateObj: Date
  description: string
  tags: string[]
  cover: string | false
  author: string
  readingTime: string
}

export default createContentLoader('posts/**/*.md', {
  excerpt: true,
  transform(rawData): Post[] {
    return rawData
      .filter(item => !item.frontmatter.hidden)
      .sort((a, b) => +new Date(b.frontmatter.date) - +new Date(a.frontmatter.date))
      .map(item => ({
        title: item.frontmatter.title || '无标题',
        url: item.url,
        date: formatDate(item.frontmatter.date),
        dateObj: new Date(item.frontmatter.date),
        description: item.frontmatter.description || '',
        tags: item.frontmatter.tags || [],
        cover: item.frontmatter.cover ?? false,
        author: item.frontmatter.author || '',
        readingTime: item.frontmatter.readingTime || '',
      }))
  }
})

function formatDate(date: string): string {
  if (!date) return ''
  const d = new Date(date)
  return `${d.getFullYear()}-${String(d.getMonth() + 1).padStart(2, '0')}-${String(d.getDate()).padStart(2, '0')}`
}
```

## 实战：时间轴归档页

### 数据加载器

```ts
// docs/archive/archive.data.ts
import { createContentLoader } from 'vitepress'

interface ArchiveItem {
  title: string
  url: string
  date: string
  year: number
  month: number
}

interface ArchiveByYear {
  year: number
  items: ArchiveItem[]
}

export default createContentLoader('posts/**/*.md', {
  transform(rawData): ArchiveByYear[] {
    const items: ArchiveItem[] = rawData
      .filter(item => !item.frontmatter.hidden && item.frontmatter.date)
      .sort((a, b) => +new Date(b.frontmatter.date) - +new Date(a.frontmatter.date))
      .map(item => {
        const d = new Date(item.frontmatter.date)
        return {
          title: item.frontmatter.title || '无标题',
          url: item.url,
          date: `${d.getMonth() + 1}/${d.getDate()}`,
          year: d.getFullYear(),
          month: d.getMonth() + 1,
        }
      })

    // 按年分组
    const grouped = new Map<number, ArchiveItem[]>()
    for (const item of items) {
      if (!grouped.has(item.year)) grouped.set(item.year, [])
      grouped.get(item.year)!.push(item)
    }

    return Array.from(grouped.entries())
      .map(([year, items]) => ({ year, items }))
      .sort((a, b) => b.year - a.year)
  }
})
```

## 实战：标签聚合页

### 数据加载器

```ts
// docs/tags/tags.data.ts
import { createContentLoader } from 'vitepress'

interface TagInfo {
  name: string
  count: number
  posts: { title: string; url: string; date: string }[]
}

export default createContentLoader('posts/**/*.md', {
  transform(rawData): TagInfo[] {
    const tagMap = new Map<string, TagInfo>()

    for (const item of rawData) {
      if (item.frontmatter.hidden) continue

      const tags: string[] = item.frontmatter.tags || item.frontmatter.tag || []
      const date = item.frontmatter.date
        ? new Date(item.frontmatter.date).toISOString().slice(0, 10)
        : ''

      for (const tag of tags) {
        if (!tagMap.has(tag)) {
          tagMap.set(tag, { name: tag, count: 0, posts: [] })
        }
        const info = tagMap.get(tag)!
        info.count++
        info.posts.push({
          title: item.frontmatter.title || '无标题',
          url: item.url,
          date,
        })
      }
    }

    return Array.from(tagMap.values())
      .sort((a, b) => b.count - a.count)
      .map(tag => ({
        ...tag,
        posts: tag.posts.sort((a, b) => b.date.localeCompare(a.date))
      }))
  }
})
```

## 实战：站点统计

### 数据加载器

```ts
// docs/stats/stats.data.ts
import { createContentLoader } from 'vitepress'

interface SiteStats {
  totalPosts: number
  totalTags: number
  totalWords: number
  latestPost: { title: string; url: string; date: string } | null
  postsByYear: Record<string, number>
  topTags: { name: string; count: number }[]
}

export default createContentLoader('posts/**/*.md', {
  includeSrc: true,
  transform(rawData): SiteStats {
    const published = rawData.filter(item => !item.frontmatter.hidden)
    const tagMap = new Map<string, number>()
    let totalWords = 0

    for (const item of published) {
      // 统计字数（中文按字符，英文按空格分词）
      if (item.src) {
        const chinese = (item.src.match(/[\u4e00-\u9fff]/g) || []).length
        const english = item.src.replace(/[\u4e00-\u9fff]/g, ' ')
          .split(/\s+/).filter(Boolean).length
        totalWords += chinese + english
      }

      // 统计标签
      const tags: string[] = item.frontmatter.tags || item.frontmatter.tag || []
      for (const tag of tags) {
        tagMap.set(tag, (tagMap.get(tag) || 0) + 1)
      }
    }

    // 按年统计
    const postsByYear: Record<string, number> = {}
    for (const item of published) {
      if (item.frontmatter.date) {
        const year = new Date(item.frontmatter.date).getFullYear().toString()
        postsByYear[year] = (postsByYear[year] || 0) + 1
      }
    }

    // 最新文章
    const sorted = published
      .filter(item => item.frontmatter.date)
      .sort((a, b) => +new Date(b.frontmatter.date) - +new Date(a.frontmatter.date))

    const latest = sorted[0]

    return {
      totalPosts: published.length,
      totalTags: tagMap.size,
      totalWords,
      latestPost: latest
        ? { title: latest.frontmatter.title, url: latest.url, date: latest.frontmatter.date }
        : null,
      postsByYear,
      topTags: Array.from(tagMap.entries())
        .map(([name, count]) => ({ name, count }))
        .sort((a, b) => b.count - a.count)
        .slice(0, 10),
    }
  }
})
```

## 实战：RSS 生成

在 `buildEnd` 钩子中使用 `createContentLoader` 生成 RSS：

```ts
// docs/.vitepress/config.ts
import { createContentLoader, defineConfig } from 'vitepress'
import { writeFileSync } from 'node:fs'
import { resolve } from 'node:path'

const SITE_URL = 'https://docs.example.com'

export default defineConfig({
  async buildEnd(siteConfig) {
    // 使用 createContentLoader 获取所有文章
    const posts = await createContentLoader('posts/**/*.md', {
      excerpt: true,
      render: true,
    }).load()

    // 按日期排序
    posts.sort((a, b) =>
      +new Date(b.frontmatter.date) - +new Date(a.frontmatter.date)
    )

    // 生成 RSS XML
    const rss = `<?xml version="1.0" encoding="UTF-8"?>
<rss version="2.0" xmlns:atom="http://www.w3.org/2005/Atom">
  <channel>
    <title>My Blog</title>
    <link>${SITE_URL}</link>
    <description>技术博客</description>
    <language>zh-CN</language>
    <lastBuildDate>${new Date().toUTCString()}</lastBuildDate>
    <atom:link href="${SITE_URL}/feed.xml" rel="self" type="application/rss+xml"/>
    ${posts.map(post => `
    <item>
      <title>${escapeXml(post.frontmatter.title)}</title>
      <link>${SITE_URL}${post.url}</link>
      <pubDate>${new Date(post.frontmatter.date).toUTCString()}</pubDate>
      <description>${escapeXml(post.frontmatter.description || '')}</description>
      <guid isPermaLink="true">${SITE_URL}${post.url}</guid>
    </item>`).join('')}
  </channel>
</rss>`

    // 写入文件
    const outPath = resolve(siteConfig.outDir, 'feed.xml')
    writeFileSync(outPath, rss)
    console.log(`RSS feed generated: ${outPath}`)
  }
})

function escapeXml(str: string): string {
  return str
    .replace(/&/g, '&amp;')
    .replace(/</g, '&lt;')
    .replace(/>/g, '&gt;')
    .replace(/"/g, '&quot;')
    .replace(/'/g, '&apos;')
}
```

## 自定义 Data Loader

不限于 Markdown，可以加载任何数据：

### 加载 CSV

```ts
// docs/data/csv.data.ts
import fs from 'node:fs'
import { parse } from 'csv-parse/sync'

export default {
  watch: ['./data/*.csv'],
  load(watchedFiles: string[]) {
    return watchedFiles.flatMap(file => {
      return parse(fs.readFileSync(file, 'utf-8'), {
        columns: true,
        skip_empty_lines: true
      })
    })
  }
}
```

### 加载 JSON

```ts
// docs/data/team.data.ts
import fs from 'node:fs'
import { resolve } from 'node:path'

export default {
  watch: ['./data/team.json'],
  load() {
    const raw = fs.readFileSync(resolve(__dirname, '../data/team.json'), 'utf-8')
    return JSON.parse(raw)
  }
}
```

### 加载远程 API

```ts
// docs/data/github.data.ts
export default {
  async load() {
    const res = await fetch('https://api.github.com/repos/vuejs/vitepress')
    const data = await res.json()
    return {
      stars: data.stargazers_count,
      forks: data.forks_count,
      issues: data.open_issues_count,
    }
  }
}
```

### 加载目录结构

```ts
// docs/data/structure.data.ts
import fs from 'node:fs'
import path from 'node:path'

export default {
  watch: ['docs/**/*.md'],
  load(watchedFiles: string[]) {
    const structure: Record<string, string[]> = {}

    for (const file of watchedFiles) {
      const relative = path.relative(path.resolve(__dirname, '..'), file)
      const dir = path.dirname(relative)
      if (!structure[dir]) structure[dir] = []
      structure[dir].push(path.basename(file))
    }

    return structure
  }
}
```

## 性能与注意事项

### 数据大小

构建时加载的数据会序列化为 JSON 内联到客户端 JS 中：

```ts
// ❌ 不要加载太多数据
createContentLoader('**/*.md', {
  includeSrc: true,    // 源码很大
  render: true,        // HTML 也很大
  excerpt: true,       // 摘要也加上
  transform(data) {
    return data         // 原样返回，数据量巨大
  }
})

// ✅ 只提取需要的字段
createContentLoader('**/*.md', {
  transform(data) {
    return data.map(item => ({
      title: item.frontmatter.title,
      date: item.frontmatter.date,
      url: item.url,
      tags: item.frontmatter.tags || [],
    }))
  }
})
```

### 缓存机制

- `createContentLoader` 会根据文件修改时间缓存结果
- 开发模式下修改 .md 文件会自动重新加载
- 构建时只执行一次

### watch 选项

自定义 loader 需要手动设置 watch，否则修改文件不会触发更新：

```ts
export default {
  watch: ['./data/*.json'],    // 监听文件变化
  load() { /* ... */ }
}
```

### 构建钩子中使用

```ts
// config.ts
export default defineConfig({
  async buildEnd(siteConfig) {
    const posts = await createContentLoader('posts/*.md').load()
    // 可以用于生成 RSS、sitemap、搜索索引等
  }
})
```
