## 方案一：原生 VitePress 搭建博客

纯手动方式，利用 VitePress 自带能力 + 少量自定义代码实现博客功能。

### 安装

```bash
npm add -D vitepress
```

### 目录结构

```
docs/
├── .vitepress/
│   └── config.ts
├── index.md              # 首页（Hero 布局）
├── posts/
│   ├── 2024-01-hello.md
│   ├── 2024-02-vitepress.md
│   └── 2024-03-deploy.md
└── components/
    └── PostList.vue       # 文章列表组件（需自写）
```

### 首页配置

```markdown
---
layout: home
hero:
  name: "我的博客"
  text: "记录技术与生活"
  tagline: 基于 VitePress 构建
  actions:
    - theme: brand
      text: 开始阅读
      link: /posts/
features:
  - icon: ✍️
    title: 技术文章
    details: 前端、后端、DevOps
  - icon: 📖
    title: 学习笔记
    details: 读书、课程、思考
---
```

### 手动维护文章列表

在 `docs/posts/index.md` 中手动维护：

```markdown
# 文章列表

## 2024

### 三月
- [部署 VitePress 到 GitHub Pages](/posts/2024-03-deploy)

### 二月
- [VitePress 入门教程](/posts/2024-02-vitepress)

### 一月
- [Hello World](/posts/2024-01-hello)
```

### 自动生成文章列表（Node.js 脚本）

```ts
// .vitepress/gen-post-list.ts
import fs from 'node:fs'
import path from 'node:path'

const postsDir = path.resolve(__dirname, '../posts')
const files = fs.readdirSync(postsDir)
  .filter(f => f.endsWith('.md') && f !== 'index.md')
  .sort((a, b) => b.locale.a)  // 倒序

const lines = ['# 文章列表\n']
let currentYear = ''

for (const file of files) {
  const year = file.slice(0, 4)
  if (year !== currentYear) {
    lines.push(`\n## ${year}\n`)
    currentYear = year
  }
  const title = file.replace(/^\d{4}-\d{2}-/, '').replace(/\.md$/, '')
  lines.push(`- [${title}](/posts/${file.replace(/\.md$/, '')})`)
}

fs.writeFileSync(path.join(postsDir, 'index.md'), lines.join('\n'))
```

### 优缺点

| 维度 | 评价 |
|------|------|
| ✅ 优点 | 完全可控，无额外依赖 |
| ✅ 优点 | 轻量，构建速度快 |
| ✅ 优点 | 官方维护，升级无忧 |
| ❌ 缺点 | 无标签/分类/归档功能 |
| ❌ 缺点 | 文章列表需手动或脚本维护 |
| ❌ 缺点 | 无 RSS、评论等博客常见功能 |
| ❌ 缺点 | 开发成本高，需自写 Vue 组件 |

## 方案二：sugar-blog 主题（@sugarat/theme）

由 [ATQQ](https://github.com/ATQQ/sugar-blog) 开发的 VitePress 博客主题，功能丰富，中文社区活跃。

### 安装

```bash
npm add -D vitepress @sugarat/theme
```

### 配置

```ts
// .vitepress/config.ts
import { defineConfig } from 'vitepress'
import { blogTheme } from '@sugarat/theme'

export default defineConfig({
  extends: blogTheme,
  themeConfig: {
    blog: {
      // 博客配置
      author: '你的名字',
      description: '个人博客',
      // 头像
      avatar: '/avatar.png',
      // 文章默认封面图
      coverImg: '/default-cover.png',
      // 文章目录
      postDir: 'posts',
      // 分类
      categories: [
        { text: '前端', dir: 'frontend' },
        { text: '后端', dir: 'backend' }
      ]
    }
  }
})
```

### 文章 frontmatter

```markdown
---
title: VitePress 入门教程
date: 2024-03-15
tags:
  - vitepress
  - 教程
categories:
  - 前端
description: 从零开始搭建 VitePress 文档
cover: /covers/vitepress.png
top: true    # 置顶
---

# VitePress 入门教程

正文内容...
```

### 核心功能

| 功能 | 说明 |
|------|------|
| 📝 文章列表 | 自动生成，支持分页 |
| 🏷️ 标签系统 | frontmatter `tags` 自动聚合 |
| 📂 分类系统 | 按 `categories` 或目录自动分类 |
| 📅 时间轴 | 按日期归档的文章列表 |
| 📌 置顶文章 | frontmatter `top: true` |
| 🔍 搜索 | 内置本地搜索 |
| 🖼️ 封面图 | 每篇文章可设置封面 |
| 👤 作者信息 | 首页展示头像、简介 |
| 📱 响应式 | 移动端适配 |
| 🌙 暗黑模式 | 跟随系统或手动切换 |
| 📖 RSS | 可选配置 |

### 目录结构

```
docs/
├── .vitepress/
│   └── config.ts
├── index.md
├── posts/
│   ├── frontend/
│   │   ├── 2024-01-vitepress.md
│   │   └── 2024-02-vue3.md
│   └── backend/
│       └── 2024-03-nodejs.md
└── public/
    ├── avatar.png
    └── covers/
```

### 优缺点

| 维度 | 评价 |
|------|------|
| ✅ 优点 | 开箱即用，功能全面 |
| ✅ 优点 | 标签/分类/归档/置顶/分页全有 |
| ✅ 优点 | 中文文档完善，社区活跃 |
| ✅ 优点 | 基于 VitePress 扩展，兼容 Markdown |
| ✅ 优点 | 支持自定义组件覆盖 |
| ❌ 缺点 | 依赖第三方，升级可能有 breaking changes |
| ❌ 缺点 | 主题样式偏固定，深度定制需看源码 |
| ❌ 构建体积 | 比原生稍大（多了博客相关组件） |
| ❌ 缺点 | 英文社区较小 |

## 方案三：vitepress-blog-pure

由 [airene](https://github.com/airene/vitepress-blog-pure) 开发的轻量博客主题，追求极简。

### 安装

```bash
npm add -D vitepress vitepress-blog-pure
```

### 配置

```ts
// .vitepress/config.ts
import { defineConfig } from 'vitepress'

export default defineConfig({
  themeConfig: {
    blog: {
      author: '你的名字',
      // 其他配置...
    }
  }
})
```

### 核心功能

| 功能 | 说明 |
|------|------|
| 📝 文章列表 | 自动生成 |
| 🏷️ 标签 | 基础标签支持 |
| 📅 时间轴 | 按日期归档 |
| 🌙 暗黑模式 | 支持 |

### 优缺点

| 维度 | 评价 |
|------|------|
| ✅ 优点 | 极简轻量，加载快 |
| ✅ 优点 | 样式简洁美观 |
| ✅ 优点 | 上手简单 |
| ❌ 缺点 | 功能较少（无分类/置顶/分页） |
| ❌ 缺点 | 维护频率较低 |
| ❌ 缺点 | 中文文档不够完善 |
| ❌ 缺点 | 社区较小，遇到问题难找答案 |

## 选型建议

### 选原生 VitePress，如果你：

- 只需要简单的文档 + 少量文章
- 不需要标签/分类等博客功能
- 追求极致轻量和完全可控
- 有能力自写 Vue 组件

### 选 sugar-blog，如果你：

- 想要一个**功能完整**的博客
- 需要标签、分类、归档、分页、置顶
- 希望**开箱即用**，少写代码
- 面向中文读者（中文社区支持好）
- 愿意接受第三方主题的约束

### 选 blog-pure，如果你：

- 喜欢极简风格
- 只需要基础的文章列表和标签
- 不需要分类、分页等复杂功能
- 追求轻量快速

### 混合方案（文档 + 博客）

如果你既需要文档又需要博客，推荐结构：

```
docs/
├── index.md              # 首页（选择性展示）
├── guide/                # 文档区（原生侧边栏）
│   └── ...
├── blog/                 # 博客区（用 sugar-blog）
│   └── posts/
└── .vitepress/
    └── config.ts         # 分区配置 sidebar
```

```ts
// config.ts - 分区侧边栏
sidebar: {
  '/guide/': [/* 文档侧边栏 */],
  '/blog/': false  // 博客区不需要侧边栏
}
```
