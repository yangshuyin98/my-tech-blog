## 快速开始

### 安装

```bash
# 初始化项目
npm init -y

# 安装 VitePress
npm add -D vitepress
```

### 目录结构

```
docs/
├── .vitepress/
│   └── config.ts          # 核心配置文件
├── index.md               # 首页
├── guide/
│   ├── index.md           # 指南首页
│   ├── getting-started.md
│   └── configuration.md
├── api/
│   ├── index.md
│   └── markdown.md
└── sidebar-guide.md       # 侧边导航教程（独立）
```

### 启动脚本

在 `package.json` 中添加：

```json
{
  "scripts": {
    "docs:dev": "vitepress dev docs",
    "docs:build": "vitepress build docs",
    "docs:preview": "vitepress preview docs"
  }
}
```

## 首页设置

首页由 `docs/index.md` 控制，使用 YAML frontmatter 定义布局和内容。

### 基础首页（Hero 模式）

```markdown
---
layout: home

hero:
  name: "My Project"
  text: "项目副标题"
  tagline: 一句话描述你的项目
  image:
    src: /logo.png
    alt: Logo
  actions:
    - theme: brand
      text: 快速开始
      link: /guide/getting-started
    - theme: alt
      text: GitHub
      link: https://github.com/your-repo

features:
  - icon: ⚡
    title: 极速构建
    details: 基于 Vite，开发体验极佳
  - icon: 🛠️
    title: 灵活配置
    details: 支持 Markdown 扩展和自定义组件
  - icon: 📦
    title: 开箱即用
    details: 零配置即可部署
---
```

### 首页字段说明

| 字段 | 说明 |
|------|------|
| `hero.name` | 主标题，通常显示为大号文字 |
| `hero.text` | 副标题 |
| `hero.tagline` | 简短描述，显示在副标题下方 |
| `hero.image` | Hero 区域的图片（可选） |
| `hero.actions` | 按钮组，`theme` 可选 `brand`（主色）或 `alt`（次要） |
| `features` | 特性卡片，每项包含 `icon`、`title`、`details` |

### Features 列表布局

Features 默认 3 列排列。可以通过 `features.columns` 控制：

```yaml
features:
  - icon: ⚡
    title: 极速
    details: 描述文字
    link: /guide/xxx        # 可选：点击跳转
    linkText: 了解更多       # 可选：链接文字
```

### 纯文档首页（不用 Hero）

如果你不需要 Hero 区域，直接用普通 Markdown：

```markdown
---
layout: doc
---

# 欢迎

这里是文档内容...
```

## 导航栏管理

导航栏配置在 `.vitepress/config.ts` 的 `themeConfig.nav` 中。

### 基础结构

```ts
// .vitepress/config.ts
import { defineConfig } from 'vitepress'

export default defineConfig({
  themeConfig: {
    nav: [
      { text: '首页', link: '/' },
      { text: '指南', link: '/guide/' },
      { text: 'API', link: '/api/' }
    ]
  }
})
```

### 带下拉菜单

```ts
nav: [
  { text: '首页', link: '/' },
  {
    text: '指南',
    items: [
      { text: '快速开始', link: '/guide/getting-started' },
      { text: '配置', link: '/guide/configuration' },
      {
        text: '进阶',
        items: [
          { text: '自定义主题', link: '/guide/custom-theme' },
          { text: '插件开发', link: '/guide/plugin' }
        ]
      }
    ]
  }
]
```

> **注意：** `items` 支持嵌套，实现多级下拉菜单。

### 分组下拉（带分隔线）

```ts
nav: [
  {
    text: '版本',
    items: [
      {
        text: '当前版本',
        items: [
          { text: 'v2.0.0 (最新)', link: '/versions/v2' },
          { text: 'v1.x', link: '/versions/v1' }
        ]
      },
      {
        text: '变更日志',
        link: '/changelog'
      }
    ]
  }
]
```

### 外部链接

```ts
nav: [
  {
    text: 'GitHub',
    link: 'https://github.com/your-repo',
    target: '_blank'
  }
]
```

### 导航栏 Logo

```ts
themeConfig: {
  siteTitle: 'My Docs',           // Logo 文字
  logo: '/logo.svg',               // Logo 图片（放在 public/ 目录）
}
```

### 导航栏社交链接

```ts
themeConfig: {
  socialLinks: [
    { icon: 'github', link: 'https://github.com/your-repo' },
    { icon: 'twitter', link: 'https://twitter.com/your-handle' },
    { icon: 'discord', link: 'https://discord.gg/your-invite' }
  ]
}
```

### 搜索框

```ts
themeConfig: {
  search: {
    provider: 'local'    // 本地搜索，无需外部服务
    // 或使用 Algolia：
    // provider: 'algolia',
    // options: { appId: '...', apiKey: '...', indexName: '...' }
  }
}
```

## 完整配置示例

一个包含首页、导航、搜索的完整 `config.ts`：

```ts
import { defineConfig } from 'vitepress'

export default defineConfig({
  title: 'My Docs',
  description: '项目文档',

  // 首页的 base 路径（部署到子路径时需要）
  // base: '/my-project/',

  themeConfig: {
    // Logo
    logo: '/logo.svg',
    siteTitle: 'My Docs',

    // 导航栏
    nav: [
      { text: '首页', link: '/' },
      {
        text: '指南',
        items: [
          { text: '快速开始', link: '/guide/' },
          { text: '配置详解', link: '/guide/configuration' }
        ]
      },
      { text: 'API 参考', link: '/api/' },
      { text: 'GitHub', link: 'https://github.com/xxx' }
    ],

    // 侧边导航 → 见 sidebar-guide.md
    sidebar: {
      '/guide/': [
        {
          text: '指南',
          items: [
            { text: '快速开始', link: '/guide/' },
            { text: '配置详解', link: '/guide/configuration' }
          ]
        }
      ],
      '/api/': [
        {
          text: 'API',
          items: [
            { text: '概览', link: '/api/' },
            { text: 'Markdown 扩展', link: '/api/markdown' }
          ]
        }
      ]
    },

    // 搜索
    search: { provider: 'local' },

    // 社交链接
    socialLinks: [
      { icon: 'github', link: 'https://github.com/xxx' }
    ],

    // 页脚
    footer: {
      message: 'Released under the MIT License.',
      copyright: 'Copyright © 2024'
    }
  }
})
```
