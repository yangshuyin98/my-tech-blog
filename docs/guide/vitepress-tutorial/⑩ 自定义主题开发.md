## 主题基础架构

VitePress 主题是一个导出特定接口的对象：

```ts
interface Theme {
  /** 根布局组件（必须） */
  Layout: Component
  /** 增强 Vue 应用（可选） */
  enhanceApp?: (ctx: EnhanceAppContext) => Awaitable<void>
  /** 扩展其他主题（可选） */
  extends?: Theme
}
```

**最小主题 = 一个 Vue 组件：**

```ts
// .vitepress/theme/index.ts
import Layout from './Layout.vue'

export default { Layout }
```

## 从零创建主题

### 步骤 1：创建主题入口文件

```
docs/
├── .vitepress/
│   ├── config.ts
│   └── theme/
│       ├── index.ts        # 主题入口
│       ├── Layout.vue       # 根布局
│       ├── Home.vue         # 首页布局
│       ├── Page.vue         # 文档页布局
│       ├── NotFound.vue     # 404 页面
│       └── custom.css       # 自定义样式
└── index.md
```

### 步骤 2：创建根布局 Layout.vue

```vue
<!-- .vitepress/theme/Layout.vue -->
<script setup>
import { useData } from 'vitepress'
import Home from './Home.vue'
import Page from './Page.vue'
import NotFound from './NotFound.vue'

const { frontmatter, page } = useData()
</script>

<template>
  <div class="my-theme">
    <!-- 404 -->
    <NotFound v-if="page.isNotFound" />

    <!-- 首页 -->
    <Home v-else-if="frontmatter.layout === 'home'" />

    <!-- 文档页 -->
    <Page v-else />
  </div>
</template>

<style>
.my-theme {
  min-height: 100vh;
}
</style>
```

## 扩展默认主题

大多数时候，你不需要从零开始。扩展默认主题更实用：

```ts
// .vitepress/theme/index.ts
import DefaultTheme from 'vitepress/theme'
import MyComponent from './components/MyComponent.vue'
import './custom.css'

export default {
  extends: DefaultTheme,      // 继承默认主题
  enhanceApp({ app }) {
    app.component('MyComponent', MyComponent)  // 添加全局组件
  },
  // 可选：覆盖布局
  Layout() {
    return h(DefaultTheme.Layout, null, {
      // 插槽覆盖
      'nav-bar-title-after': () => h(MyLogo),
      'doc-footer-before': () => h(FeedbackButton),
    })
  }
}
```

### 默认主题的插槽

扩展默认主题时，可以通过插槽注入内容：

| 插槽名 | 位置 |
|--------|------|
| `layout-top` | 页面最顶部 |
| `layout-bottom` | 页面最底部 |
| `nav-bar-title-after` | 导航栏标题后 |
| `nav-bar-content-before` | 导航栏内容前 |
| `nav-screen-content-after` | 移动端导航后 |
| `sidebar-nav-before` | 侧边栏导航前 |
| `sidebar-nav-after` | 侧边栏导航后 |
| `doc-before` | 文档内容前 |
| `doc-after` | 文档内容后 |
| `doc-footer-before` | 文档页脚前 |
| `doc-footer-after` | 文档页脚后 |
| `aside-top` | 右侧栏顶部 |
| `aside-bottom` | 右侧栏底部 |
| `aside-outline-before` | 目录前 |
| `aside-outline-after` | 目录后 |
| `home-hero-before` | 首页 Hero 前 |
| `home-hero-after` | 首页 Hero 后 |
| `home-features-before` | 首页特性前 |
| `home-features-after` | 首页特性后 |

### 使用插槽示例

```ts
// .vitepress/theme/index.ts
import { h } from 'vue'
import DefaultTheme from 'vitepress/theme'
import Announcement from './components/Announcement.vue'
import BackToTop from './components/BackToTop.vue'

export default {
  extends: DefaultTheme,
  Layout() {
    return h(DefaultTheme.Layout, null, {
      // 在页面顶部显示公告
      'layout-top': () => h(Announcement),
      // 在文档页脚前添加返回顶部
      'doc-footer-before': () => h(BackToTop),
    })
  }
}
```

## 布局系统

### 多布局支持

通过 frontmatter 的 `layout` 字段切换布局：

```markdown
---
layout: home      # 使用 Home.vue
---

# 首页内容
```

```markdown
---
layout: doc       # 使用默认文档布局
---

# 文档内容
```

```markdown
---
layout: page      # 纯页面布局（无侧边栏）
---

# 自定义页面
```

### 自定义布局

```vue
<!-- .vitepress/theme/Layout.vue -->
<script setup>
import { useData } from 'vitepress'

const { frontmatter } = useData()

// 布局映射
const layouts = {
  home: () => import('./Home.vue'),
  page: () => import('./Page.vue'),
  doc: () => import('./Doc.vue'),
}

const layoutKey = frontmatter.value.layout || 'doc'
</script>
```

## useData 运行时 API

`useData()` 是主题开发的核心 Hook，提供所有运行时数据：

```ts
import { useData } from 'vitepress'

const {
  page,          // 当前页面数据
  frontmatter,   // 当前页面 frontmatter
  theme,         // 主题配置
  site,          // 站点配置
  title,         // 页面标题
  description,   // 页面描述
  lang,          // 语言
  localePath,    // locale 路径
  isDark,        // 是否暗黑模式
  dir,           // 文本方向
} = useData()
```

### 常用场景

```vue
<script setup>
import { useData } from 'vitepress'
const { page, frontmatter, isDark, theme } = useData()
</script>

<template>
  <!-- 根据 frontmatter 切换布局 -->
  <div v-if="frontmatter.layout === 'home'">首页</div>

  <!-- 暗黑模式适配 -->
  <img :src="isDark ? '/logo-dark.png' : '/logo-light.png'" />

  <!-- 使用主题配置 -->
  <footer>{{ theme.footer?.copyright }}</footer>

  <!-- 页面信息 -->
  <span>{{ page.title }}</span>
</template>
```

## 样式定制

### CSS 变量覆盖

VitePress 定义了大量 CSS 变量，覆盖即可：

```css
/* .vitepress/theme/custom.css */

:root {
  /* 品牌色 */
  --vp-c-brand: #3451b2;
  --vp-c-brand-light: #3a5ccc;
  --vp-c-brand-lighter: #5672cd;
  --vp-c-brand-dark: #2a3f91;
  --vp-c-brand-darker: #22347a;

  /* 背景色 */
  --vp-c-bg: #ffffff;
  --vp-c-bg-soft: #f6f6f7;
  --vp-c-bg-mute: #e8e8e8;

  /* 文字色 */
  --vp-c-text-1: rgba(60, 60, 67);
  --vp-c-text-2: rgba(60, 60, 67, 0.78);
  --vp-c-text-3: rgba(60, 60, 67, 0.56);

  /* 间距 */
  --vp-nav-height: 64px;
  --vp-sidebar-width: 272px;

  /* 字体 */
  --vp-font-family-base: 'Inter', -apple-system, sans-serif;
  --vp-font-family-mono: 'Fira Code', monospace;
}

/* 暗黑模式 */
.dark {
  --vp-c-bg: #1a1a1a;
  --vp-c-text-1: rgba(255, 255, 255, 0.87);
}
```

### 全部 CSS 变量

VitePress 提供的 CSS 变量非常多，常用的分类：

| 分类 | 变量前缀 | 说明 |
|------|---------|------|
| 品牌色 | `--vp-c-brand-*` | 主题色相关 |
| 背景 | `--vp-c-bg-*` | 页面背景 |
| 文字 | `--vp-c-text-*` | 文字颜色 |
| 边框 | `--vp-c-divider-*` | 分割线 |
| 链接 | `--vp-c-link` | 链接颜色 |
| 按钮 | `--vp-button-*` | 按钮样式 |
| 代码块 | `--vp-code-*` | 代码块样式 |
| 侧边栏 | `--vp-sidebar-*` | 侧边栏 |
| 导航栏 | `--vp-nav-*` | 导航栏 |

### 自定义组件样式

```css
/* 覆盖默认主题的特定组件 */

/* 修改导航栏背景 */

/* 修改侧边栏样式 */

/* 修改代码块圆角 */
```

## 全局组件注册

### 常见全局组件

```ts
// .vitepress/theme/index.ts
import DefaultTheme from 'vitepress/theme'

// 常用全局组件
import Badge from './components/Badge.vue'
import TeamMember from './components/TeamMember.vue'
import CodeSandbox from './components/CodeSandbox.vue'
import ArticleMetadata from './components/ArticleMetadata.vue'

export default {
  extends: DefaultTheme,
  enhanceApp({ app }) {
    app.component('Badge', Badge)
    app.component('TeamMember', TeamMember)
    app.component('CodeSandbox', CodeSandbox)
    app.component('ArticleMetadata', ArticleMetadata)
  }
}
```

### 使用 Vue 插件

```ts
import DefaultTheme from 'vitepress/theme'
import MyPlugin from './plugins/my-plugin'

export default {
  extends: DefaultTheme,
  enhanceApp({ app }) {
    app.use(MyPlugin)
  }
}
```

## 完整主题示例

一个带导航、侧边栏、搜索、暗黑模式的完整主题：

```ts
// .vitepress/theme/index.ts
import { h } from 'vue'
import DefaultTheme from 'vitepress/theme'
import type { Theme } from 'vitepress'

// 组件
import Announcement from './components/Announcement.vue'
import BackToTop from './components/BackToTop.vue'
import ArticleMeta from './components/ArticleMeta.vue'
import Badge from './components/Badge.vue'
import CopyCodeButton from './components/CopyCodeButton.vue'

// 样式
import './styles/vars.css'
import './styles/custom.css'
import './styles/animations.css'

export default {
  extends: DefaultTheme,

  Layout() {
    return h(DefaultTheme.Layout, null, {
      'layout-top': () => h(Announcement),
      'doc-footer-before': () => h(BackToTop),
      'doc-before': () => h(ArticleMeta),
    })
  },

  enhanceApp({ app }) {
    app.component('Badge', Badge)
    app.component('CopyCodeButton', CopyCodeButton)
  }
} satisfies Theme
```

## 发布主题

### 作为 npm 包发布

```json
// package.json
{
  "name": "vitepress-theme-mytheme",
  "version": "1.0.0",
  "main": "src/theme/index.ts",
  "exports": {
    ".": "./src/theme/index.ts",
    "./config": "./src/config.ts"
  }
}
```

### 使用者接入

```ts
// 使用者 .vitepress/theme/index.ts
import Theme from 'vitepress-theme-mytheme'
export default Theme

// 使用者 .vitepress/config.ts
import baseConfig from 'vitepress-theme-mytheme/config'
export default defineConfig({
  extends: baseConfig,
  themeConfig: {
    // 主题配置
  }
})
```

### 发布到 GitHub 模板仓库

1. 创建 GitHub 仓库
2. 设置为 Template Repository
3. 使用者通过 `Use this template` 创建项目
