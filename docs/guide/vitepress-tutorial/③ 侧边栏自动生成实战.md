## 核心结论

| | 侧边栏 | 导航栏 |
|---|---|---|
| **文件数量** | 多（几十到几百） | 少（3-6 个） |
| **变动频率** | 高（每次写文章） | 低（偶尔调整） |
| **自动生成收益** | 大 | 小 |
| **推荐** | ✅ 自动生成 | ❌ 手写 |

**一句话：** 侧边栏跟着文件走，自动化；导航栏跟着产品走，手写。

---

## 为什么侧边栏要自动生成

手动维护侧边栏的真实痛点：

```
你有 50 篇文章，分布在 5 个目录下。
今天你新增了一篇，改名了一篇，删了一篇。
→ 你要打开 config.ts，找到对应目录，加一项、改一项、删一项。
→ 你忘了改，读者点进去 404。
```

**自动化 = 零心智负担。** 增删文件只管操作文件，侧边栏自动跟着变。

---

## 为什么导航栏不推荐自动生成

导航栏是**信息架构**，不是文件索引：

```ts
// ❌ 自动生成可能暴露你不想展示的目录
nav: [
  { text: '指南', link: '/guide/' },
  { text: '草稿', link: '/drafts/' },      // 不想让人看到
  { text: '内部文档', link: '/internal/' },  // 不想让人看到
]

// ✅ 手写：精确控制展示什么
nav: [
  { text: '首页', link: '/' },
  { text: '指南', link: '/guide/' },
  { text: '博客', link: '/posts/' },
]
```

导航栏就 3-6 项，一年改不了几次，手写成本为零。

## 方案一：数字前缀 + 脚本扫描

> **适合：** 个人博客，文件 < 50，不想装插件

### 思路

文件名加数字前缀，脚本按前缀排序生成侧边栏。

### 目录结构

```
docs/
├── .vitepress/
│   ├── config.ts
│   └── sidebar.ts          # 自动生成脚本
├── guide/
│   ├── index.md
│   ├── 01.介绍.md
│   ├── 02.快速开始.md
│   ├── 03.配置详解.md
│   └── 04.部署上线.md
├── posts/
│   ├── index.md
│   ├── 01.vue3入门.md
│   ├── 02.react核心概念.md
│   └── 03.nodejs实战.md
└── index.md
```

### 脚本实现

```ts
// docs/.vitepress/sidebar.ts
import fs from 'node:fs'
import path from 'node:path'

/**
 * 扫描目录，自动生成侧边栏
 * @param dir     相对于 docs/ 的目录路径
 * @param title   分组标题
 * @param options 可选配置
 */
function autoSidebar(
  dir: string,
  title: string,
  options: {
    /** 是否隐藏 index.md，默认 true */
    hideIndex?: boolean
    /** 自定义排序函数 */
    sort?: (a: string, b: string) => number
  } = {}
) {
  const { hideIndex = true, sort } = options
  const dirPath = path.resolve(__dirname, '..', dir)

  if (!fs.existsSync(dirPath)) return []

  let files = fs.readdirSync(dirPath)
    .filter(f => f.endsWith('.md'))
    .filter(f => (hideIndex ? f !== 'index.md' : true))

  // 排序：数字前缀优先，否则按字母
  if (sort) {
    files = files.sort(sort)
  } else {
    files = files.sort((a, b) => {
      const numA = parseInt(a.match(/^(\d+)/)?.[1] ?? '999')
      const numB = parseInt(b.match(/^(\d+)/)?.[1] ?? '999')
      if (numA !== numB) return numA - numB
      return a.localeCompare(b)
    })
  }

  const items = files.map(f => {
    const name = f.replace(/^\d+\./, '').replace(/\.md$/, '')
    const link = `/${dir}/${f.replace(/\.md$/, '')}`
    return { text: name, link }
  })

  return items.length ? [{ text: title, items }] : []
}

// ====== 导出侧边栏配置 ======
export const sidebar = {
  '/guide/': autoSidebar('guide', '📖 指南'),
  '/posts/': autoSidebar('posts', '✍️ 文章'),
  '/api/': autoSidebar('api', '📦 API'),
}
```

### config.ts 中引用

```ts
// docs/.vitepress/config.ts
import { defineConfig } from 'vitepress'
import { sidebar } from './sidebar'

export default defineConfig({
  themeConfig: {
    sidebar,
    // 导航栏手写
    nav: [
      { text: '首页', link: '/' },
      { text: '指南', link: '/guide/' },
      { text: '博客', link: '/posts/' },
    ]
  }
})
```

### 效果

```
新增文件：docs/guide/05.进阶技巧.md
→ 侧边栏自动出现「进阶技巧」，排在第 5 位
→ 零配置改动
```

### 优缺点

| ✅ 优点 | ❌ 缺点 |
|---------|---------|
| 零依赖，纯 Node.js | 文件名必须带数字前缀 |
| 逻辑简单，容易理解 | 改排序需要重命名文件 |
| 增删文件零配置 | 不支持跨目录关联 |

## 方案二：frontmatter order + 脚本

> **适合：** 需要灵活排序，不想受文件名约束

### 思路

在每个 Markdown 文件的 frontmatter 中写 `order` 字段，脚本读取并排序。

### 文件示例

```markdown
---
title: 快速开始
order: 2
---

# 快速开始

正文...
```

```markdown
---
title: 介绍
order: 1
---

# 介绍

正文...
```

### 脚本实现

```ts
// docs/.vitepress/sidebar.ts
import fs from 'node:fs'
import path from 'node:path'

/**
 * 解析 Markdown 文件的 frontmatter
 */
function parseFrontmatter(filePath: string) {
  const content = fs.readFileSync(filePath, 'utf-8')
  const match = content.match(/^---\n([\s\S]*?)\n---/)
  if (!match) return {}

  const meta: Record<string, any> = {}
  const lines = match[1].split('\n')

  for (const line of lines) {
    const kv = line.match(/^(\w+):\s*(.+)/)
    if (kv) {
      const [, key, value] = kv
      // 解析数组（tags: xxx 的情况）
      if (value.startsWith('[')) {
        try { meta[key] = JSON.parse(value) } catch { meta[key] = value }
      } else if (/^\d+$/.test(value)) {
        meta[key] = parseInt(value)
      } else {
        meta[key] = value.replace(/^["']|["']$/g, '')
      }
    }
  }
  return meta
}

/**
 * 扫描目录，按 frontmatter.order 排序
 */
function autoSidebarByOrder(dir: string, title: string) {
  const dirPath = path.resolve(__dirname, '..', dir)
  if (!fs.existsSync(dirPath)) return []

  const files = fs.readdirSync(dirPath)
    .filter(f => f.endsWith('.md') && f !== 'index.md')
    .map(f => {
      const meta = parseFrontmatter(path.join(dirPath, f))
      return {
        file: f,
        title: meta.title || f.replace(/\.md$/, ''),
        order: meta.order ?? 999,
        date: meta.date || '',
      }
    })
    .sort((a, b) => {
      if (a.order !== b.order) return a.order - b.order
      // order 相同时按日期倒序
      return (b.date || '').localeCompare(a.date || '')
    })

  const items = files.map(({ file, title }) => ({
    text: title,
    link: `/${dir}/${file.replace(/\.md$/, '')}`
  }))

  return items.length ? [{ text: title, items }] : []
}

export const sidebar = {
  '/guide/': autoSidebarByOrder('guide', '📖 指南'),
  '/posts/': autoSidebarByOrder('posts', '✍️ 文章'),
}
```

### 使用方式

```markdown
---
title: 介绍
order: 1
---

# 介绍
```

```markdown
---
title: 快速开始
order: 2
---

# 快速开始
```

```markdown
---
title: 部署
order: 3
date: 2024-03-15
---

# 部署
```

### 进阶：支持隐藏

```ts
// 在 map 阶段过滤
.map(f => {
  const meta = parseFrontmatter(path.join(dirPath, f))
  return {
    file: f,
    title: meta.title || f.replace(/\.md$/, ''),
    order: meta.order ?? 999,
    hidden: meta.hidden ?? false,    // 新增
  }
})
.filter(item => !item.hidden)        // 过滤隐藏项
```

```markdown
---
title: 草稿
order: 99
hidden: true
---

# 这篇不会出现在侧边栏
```

### 优缺点

| ✅ 优点 | ❌ 缺点 |
|---------|---------|
| 文件名无约束 | 每个文件要写 frontmatter |
| 排序灵活，随时可调 | 解析 frontmatter 有性能开销 |
| 可扩展（hidden、title 等） | 需要自己写解析脚本 |

## 方案三：vitepress-plugin-sidebar 插件

> **适合：** 不想写脚本，开箱即用

### 安装

```bash
pnpm add -D vitepress-plugin-sidebar
```

### 配置

```ts
// docs/.vitepress/config.ts
import { defineConfig } from 'vitepress'
import { getSidebar } from 'vitepress-plugin-sidebar'

export default defineConfig({
  themeConfig: {
    // 自动扫描 docs/ 下所有目录
    sidebar: getSidebar('./docs', {
      // 忽略的文件
      ignoreFiles: ['index.md'],
      // 从文件第一个 # 标题提取文字作为侧边栏文本
      titleFromFile: true,
    }),
    // 导航栏手写
    nav: [
      { text: '首页', link: '/' },
      { text: '指南', link: '/guide/' },
      { text: '博客', link: '/posts/' },
    ]
  }
})
```

### 效果

```
docs/guide/01.介绍.md
→ 侧边栏显示：介绍（取自 # 标题 或文件名）

docs/guide/02.快速开始.md
→ 侧边栏显示：快速开始
```

### 优缺点

| ✅ 优点 | ❌ 缺点 |
|---------|---------|
| 零代码，配置即用 | 依赖第三方插件 |
| 自动提取标题 | 排序逻辑不如自写灵活 |
| 社区维护 | 可能有版本兼容问题 |

## 方案四：手写（少量文件适用）

> **适合：** 文档站，结构稳定，文件 < 15

### 配置

```ts
// docs/.vitepress/config.ts
export default defineConfig({
  themeConfig: {
    sidebar: {
      '/guide/': [
        {
          text: '指南',
          items: [
            { text: '介绍', link: '/guide/' },
            { text: '快速开始', link: '/guide/getting-started' },
            { text: '配置', link: '/guide/configuration' },
            { text: '部署', link: '/guide/deploy' },
          ]
        }
      ],
      '/api/': [
        {
          text: 'API',
          items: [
            { text: '概览', link: '/api/' },
            { text: 'Markdown', link: '/api/markdown' },
            { text: 'Runtime', link: '/api/runtime' },
          ]
        }
      ]
    }
  }
})
```

### 优缺点

| ✅ 优点 | ❌ 缺点 |
|---------|---------|
| 完全可控 | 文件多了维护痛苦 |
| 无依赖、无脚本 | 容易遗漏、出错 |
| 结构一目了然 | 不适合频繁增删文件 |

## 方案对比总表

| 维度 | 数字前缀 + 脚本 | frontmatter + 脚本 | 插件 | 手写 |
|------|----------------|-------------------|------|------|
| **复杂度** | ⭐ 低 | ⭐⭐ 中 | ⭐ 低 | ⭐ 最低 |
| **依赖** | 无 | 无 | 第三方插件 | 无 |
| **排序方式** | 文件名数字 | order 字段 | 文件名/标题 | 手动顺序 |
| **灵活性** | 中 | 高 | 中 | 最高 |
| **维护成本** | 低 | 中 | 最低 | 高（文件多时） |
| **适合文件数** | < 50 | 不限 | < 100 | < 15 |
| **新增文件** | 零配置 | 写 order | 零配置 | 改 config |
| **删除文件** | 零配置 | 零配置 | 零配置 | 改 config |
| **改排序** | 改文件名 | 改 order | 改文件名 | 改 config |

## 实战建议

### 按项目类型选择

| 项目类型 | 推荐方案 |
|---------|---------|
| **个人博客**（20-100 篇文章） | 方案一：数字前缀 + 脚本 |
| **团队文档**（需要灵活排序） | 方案二：frontmatter order |
| **快速上手**（不想写代码） | 方案三：vitepress-plugin-sidebar |
| **小型文档站**（< 15 页） | 方案四：手写 |
| **sugar-blog 用户** | 主题内置，无需额外配置 |

### 我的推荐组合

```
侧边栏：方案一（数字前缀 + 脚本）
导航栏：手写
```

理由：
- 脚本只有 30 行代码，没有外部依赖
- 数字前缀在文件管理器里天然有序
- 增删文件零配置，写文章只管写
- 导航栏手写，精确控制信息架构
