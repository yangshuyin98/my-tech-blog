## 基础配置

侧边栏在 `.vitepress/config.ts` 的 `themeConfig.sidebar` 中配置。

### 最简单的写法（单一路径）

```ts
export default defineConfig({
  themeConfig: {
    sidebar: [
      {
        text: '指南',
        items: [
          { text: '介绍', link: '/guide/' },
          { text: '快速开始', link: '/guide/getting-started' },
          { text: '配置', link: '/guide/configuration' }
        ]
      }
    ]
  }
})
```

这种写法对**所有页面**生效，适合文档结构单一的项目。

## 多路径分组侧边栏

当文档有多个顶级目录时，需要用**路径前缀**来区分不同侧边栏：

```ts
sidebar: {
  '/guide/': [
    {
      text: '指南',
      items: [
        { text: '介绍', link: '/guide/' },
        { text: '快速开始', link: '/guide/getting-started' },
        { text: '配置', link: '/guide/configuration' }
      ]
    }
  ],
  '/api/': [
    {
      text: 'API 参考',
      items: [
        { text: '概览', link: '/api/' },
        { text: 'Markdown', link: '/api/markdown' },
        { text: 'Runtime API', link: '/api/runtime' }
      ]
    }
  ],
  '/blog/': [
    {
      text: '博客',
      items: [
        { text: '文章列表', link: '/blog/' },
        { text: '归档', link: '/blog/archive' }
      ]
    }
  ]
}
```

**规则：** VitePress 会根据当前页面路径匹配最具体的 key。例如访问 `/guide/xxx` 时，显示 `/guide/` 对应的侧边栏。

## 可折叠分组

在分组对象上添加 `collapsed` 属性，让分组默认收起：

```ts
sidebar: {
  '/guide/': [
    {
      text: '基础',
      collapsed: false,       // 默认展开
      items: [
        { text: '介绍', link: '/guide/' },
        { text: '快速开始', link: '/guide/getting-started' }
      ]
    },
    {
      text: '进阶',
      collapsed: true,        // 默认收起
      items: [
        { text: '自定义主题', link: '/guide/custom-theme' },
        { text: '插件开发', link: '/guide/plugin' },
        { text: '构建优化', link: '/guide/build-optimization' }
      ]
    }
  ]
}
```

### 全部默认折叠

```ts
sidebar: {
  '/guide/': [
    { text: '基础', collapsed: true, items: [/* ... */] },
    { text: '进阶', collapsed: true, items: [/* ... */] }
  ]
}
```

## 自动生成侧边栏

手动维护侧边栏很麻烦，VitePress 提供了**基于文件系统**的自动生成方式。

### 方法：使用 `MultiSidebar` 或手动扫描目录

VitePress 原生不支持自动扫描，但可以通过 Node.js 脚本生成：

```ts
// .vitepress/sidebar.ts
import fs from 'node:fs'
import path from 'node:path'

/**
 * 扫描目录，自动生成侧边栏配置
 * 文件名格式: 01.xxx.md → 按数字前缀排序
 */
function generateSidebar(dir: string, title: string) {
  const dirPath = path.resolve(__dirname, '..', dir)
  const files = fs.readdirSync(dirPath)
    .filter(f => f.endsWith('.md') && f !== 'index.md')
    .sort((a, b) => {
      const numA = parseInt(a.match(/^(\d+)/)?.[1] ?? '999')
      const numB = parseInt(b.match(/^(\d+)/)?.[1] ?? '999')
      return numA - numB
    })

  return [
    {
      text: title,
      items: files.map(f => ({
        text: f.replace(/^\d+\./, '').replace(/\.md$/, ''),
        link: `/${dir}/${f.replace(/\.md$/, '')}`
      }))
    }
  ]
}

export const sidebar = {
  '/guide/': generateSidebar('guide', '指南'),
  '/api/': generateSidebar('api', 'API 参考')
}
```

然后在 `config.ts` 中引用：

```ts
import { sidebar } from './sidebar'

export default defineConfig({
  themeConfig: {
    sidebar
  }
})
```

### 使用 vitepress-plugin-sidebar 三方插件

```bash
npm add -D vitepress-plugin-sidebar
```

```ts
// config.ts
import { getSidebar } from 'vitepress-plugin-sidebar'

export default defineConfig({
  themeConfig: {
    sidebar: getSidebar('./docs', {
      // 配置项
      ignoreFiles: ['index.md'],
      titleFromFile: true  // 从文件第一个 # 标题提取文字
    })
  }
})
```

## 侧边栏排序技巧

### 方案一：数字前缀（推荐）

文件命名加数字前缀：

```
guide/
├── 01.介绍.md
├── 02.快速开始.md
├── 03.配置.md
├── 04.部署.md
└── index.md
```

手动配置时，link 去掉数字前缀：

```ts
items: [
  { text: '介绍', link: '/guide/介绍' },
  { text: '快速开始', link: '/guide/快速开始' }
]
```

### 方案二：frontmatter 排序号

在每个 md 文件头部添加：

```markdown
---
order: 1
title: 介绍
---

# 介绍
```

然后用脚本按 `order` 排序：

```ts
function generateSidebarWithOrder(dir: string, title: string) {
  const dirPath = path.resolve(__dirname, '..', dir)
  const files = fs.readdirSync(dirPath)
    .filter(f => f.endsWith('.md') && f !== 'index.md')
    .map(f => {
      const content = fs.readFileSync(path.join(dirPath, f), 'utf-8')
      const match = content.match(/^---\norder:\s*(\d+)/)
      return {
        file: f,
        order: match ? parseInt(match[1]) : 999
      }
    })
    .sort((a, b) => a.order - b.order)

  return [{
    text: title,
    items: files.map(({ file }) => ({
      text: file.replace(/\.md$/, ''),
      link: `/${dir}/${file.replace(/\.md$/, '')}`
    }))
  }]
}
```

## 嵌套子目录侧边栏

文档结构有子目录时，需要为每个子目录配置独立侧边栏：

```
guide/
├── basics/
│   ├── index.md
│   ├── intro.md
│   └── setup.md
├── advanced/
│   ├── index.md
│   ├── plugins.md
│   └── theming.md
└── index.md
```

配置：

```ts
sidebar: {
  '/guide/basics/': [
    {
      text: '基础',
      items: [
        { text: '概述', link: '/guide/basics/' },
        { text: '介绍', link: '/guide/basics/intro' },
        { text: '安装', link: '/guide/basics/setup' }
      ]
    }
  ],
  '/guide/advanced/': [
    {
      text: '进阶',
      items: [
        { text: '概述', link: '/guide/advanced/' },
        { text: '插件', link: '/guide/advanced/plugins' },
        { text: '主题', link: '/guide/advanced/theming' }
      ]
    }
  ],
  // 匹配 /guide/ 下但不在子目录的页面
  '/guide/': [
    {
      text: '指南',
      items: [
        { text: '首页', link: '/guide/' }
      ]
    }
  ]
}
```

**注意：** 更具体的路径（`/guide/basics/`）优先于宽泛路径（`/guide/`）。

## 常见问题

### Q: 侧边栏不显示？

1. 检查路径前缀是否正确匹配
2. 确保 `link` 路径以 `/` 开头
3. 确认文件确实存在于 `docs/` 目录下

### Q: 想让某个页面不显示侧边栏？

在 frontmatter 中禁用：

```markdown
---
sidebar: false
---

# 这个页面没有侧边栏
```

或者在 config 中针对特定路径禁用：

```ts
sidebar: {
  '/guide/': [/* ... */],
  // 不需要侧边栏的路径
  '/changelog': false
}
```

### Q: 如何让侧边栏跟随页面滚动高亮？

VitePress 默认开启此功能（`outline`），无需额外配置。如需调整显示层级：

```ts
// 在页面 frontmatter 中
---
outline: [2, 3]   # 显示 h2 和 h3
---
```

### Q: 侧边栏和导航栏有什么区别？

| 特性 | 导航栏（nav） | 侧边栏（sidebar） |
|------|--------------|-------------------|
| 位置 | 顶部 | 左侧 |
| 用途 | 一级页面跳转 | 文档章节导航 |
| 层级 | 通常 1-2 级 | 支持深层嵌套 |
| 路径 | 全局统一 | 按路径分组 |
