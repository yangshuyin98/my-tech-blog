# 评论系统深度集成

静态博客没有后端，评论只能依赖第三方服务。市面上主要选项有：

| 方案 | 存储 | 是否需要登录 | 优点 | 缺点 |
|------|------|-------------|------|------|
| **Giscus** | GitHub Discussions | ✅ GitHub 账号 | 开源、免费、数据在自己仓库 | 访客需 GitHub 账号 |
| **Waline** | LeanCloud / MySQL | ❌ 可选 | 支持匿名评论、功能丰富 | 需维护后端 |
| **Utterances** | GitHub Issues | ✅ GitHub 账号 | 简单、轻量 | 功能少 |
| **Twikoo** | MongoDB / Vercel | ❌ 可选 | 国内友好、支持多种登录 | 需自行部署后端 |
| **Gitalk** | GitHub Issues | ✅ GitHub 账号 | 界面好看 | GitHub Token 限制 |

推荐 **Giscus**（最省心）或 **Waline**（功能最全）。下面逐一讲解集成方式。

---

## 1. Giscus 集成（推荐）

### 1.1 前置条件

1. GitHub 仓库设为 **Public**
2. 安装 [Giscus GitHub App](https://github.com/apps/giscus)
3. 仓库开启 **Discussions**（Settings → General → Features → ✅ Discussions）

### 1.2 获取配置参数

1. 访问 [giscus.app](https://giscus.app)
2. 输入仓库名，如 `yangshuyin98/my-tech-blog`
3. 选择：Discussion 标题包含页面路径 → `pathname`
4. 选择 Category（推荐 `Announcements`）
5. 选择主题（跟你的博客 dark/light 匹配）
6. 复制生成的 `data-*` 属性和 script

### 1.3 在 VitePress 中集成

创建评论组件 `.vitepress/theme/components/GiscusComment.vue`：

```vue
<template>
  <div class="giscus-wrapper">
    <div id="giscus-comments"></div>
  </div>
</template>

<script setup>
import { onMounted, watch } from 'vue'
import { useData, useRoute } from 'vitepress'

const { isDark } = useData()
const route = useRoute()

// Giscus 配置参数
const GISCUS_CONFIG = {
  src: 'https://giscus.app/client.js',
  'data-repo': 'yangshuyin98/my-tech-blog',
  'data-repo-id': '你的 repo ID', // 从 giscus.app 获取
  'data-category': 'Announcements',
  'data-category-id': '你的 category ID',
  'data-mapping': 'pathname',
  'data-strict': '0',
  'data-reactions-enabled': '1',
  'data-emit-metadata': '0',
  'data-input-position': 'bottom',
  'data-lang': 'zh-CN',
  'data-loading': 'lazy',
  'data-theme': isDark.value ? 'dark' : 'light',
}

function loadGiscus() {
  // 移除旧实例
  const oldScript = document.getElementById('giscus-script')
  if (oldScript) {
    oldScript.remove()
  }
  const oldContainer = document.getElementById('giscus-comments')
  if (oldContainer) {
    oldContainer.innerHTML = ''
  }

  // 创建新 script
  const script = document.createElement('script')
  script.id = 'giscus-script'
  for (const [key, value] of Object.entries(GISCUS_CONFIG)) {
    script.setAttribute(key, value)
  }
  document.body.appendChild(script)
}

onMounted(() => {
  loadGiscus()
})

// 页面切换时重新加载
watch(() => route.path, () => {
  setTimeout(loadGiscus, 300)
})
</script>

<style scoped>
.giscus-wrapper {
  margin-top: 48px;
  padding-top: 32px;
  border-top: 1px solid var(--vp-c-divider);
}
</style>
```

### 1.4 注册到主题

编辑 `.vitepress/theme/index.ts`：

```typescript
import DefaultTheme from 'vitepress/theme'
import GiscusComment from './components/GiscusComment.vue'

export default {
  extends: DefaultTheme,
  enhanceApp({ app }) {
    app.component('GiscusComment', GiscusComment)
  },
}
```

### 1.5 在文章中使用

在 `.vitepress/theme/Layout.vue` 中，在文章内容下方添加：

```vue
<template>
  <Layout>
    <template #doc-after>
      <GiscusComment />
    </template>
  </Layout>
</template>

<script setup>
import DefaultTheme from 'vitepress/theme'
const { Layout } = DefaultTheme
import GiscusComment from './components/GiscusComment.vue'
</script>
```

这样所有文章页面底部都会自动显示评论区。

## 2. Waline 集成

Waline 支持匿名评论，对非 GitHub 用户更友好。

### 2.1 部署后端

#### 方案一：Vercel 一键部署

1. 点击 [Waline Vercel 部署](https://vercel.com/new/import?s=https://github.com/walinejs/waline/tree/main/example)
2. 设置环境变量（使用 LeanCloud 或 MySQL）
3. 部署后获得 API 地址 `https://xxx.vercel.app`

#### 方案二：自行部署

```bash
npm install @waline/server
npx waline-server --port 8360
```

### 2.2 前端集成

创建 `.vitepress/theme/components/WalineComment.vue`：

```vue
<template>
  <div id="waline-comments"></div>
</template>

<script setup>
import { onMounted, watch } from 'vue'
import { useRoute } from 'vitepress'

const route = useRoute()
const SERVER_URL = 'https://你的-waline-api.vercel.app'

async function initWaline() {
  // 清除旧的评论容器
  const container = document.getElementById('waline-comments')
  container.innerHTML = '<div id="waline"></div>'

  const { init } = await import('@waline/client')
  init({
    el: '#waline',
    serverURL: SERVER_URL,
    path: route.path,
    lang: 'zh-CN',
    locale: {
      placeholder: '欢迎留言...',
    },
    reaction: true, // 支持表情反应
    pageSize: 10,
  })
}

onMounted(initWaline)
watch(() => route.path, () => setTimeout(initWaline, 300))
</script>
```

安装依赖：

```bash
npm install @waline/client
```

### 2.3 注册与使用

方式与 Giscus 完全相同，只需在 Layout 中替换组件即可。

## 3. 暗黑模式适配

评论系统需要跟随博客主题切换。

### 3.1 Giscus 自动切换

```vue
<script setup>
import { watch, onMounted } from 'vue'
import { useData } from 'vitepress'

const { isDark } = useData()

function setGiscusTheme(theme) {
  const iframe = document.querySelector('.giscus-frame')
  if (iframe) {
    iframe.contentWindow.postMessage(
      { giscus: { setConfig: { theme } } },
      'https://giscus.app'
    )
  }
}

watch(isDark, (dark) => {
  setGiscusTheme(dark ? 'dark' : 'light')
})
</script>
```

### 3.2 Waline 自动切换

Waline 支持 CSS 变量覆盖，在主题中添加：

```css
:root {
  --waline-color: var(--vp-c-text-1);
  --waline-bgcolor: var(--vp-c-bg);
  --waline-border-color: var(--vp-c-divider);
}
```

## 4. 评论管理

### Giscus 管理

所有评论存储在 GitHub Discussions 中，可以在仓库的 Discussions 标签页中：

- 审核和删除评论
- 回复评论（会在评论区显示）
- 置顶重要讨论
- 设置分类标签

### Waline 管理

Waline 有管理后台：`你的API地址/ui/login`

- 登录后可审核、删除评论
- 查看评论统计
- 设置敏感词过滤
- 导出评论数据

## 5. 最佳实践

### 5.1 评论加载策略

```typescript
// 滚动到评论区时才加载
function loadOnScroll() {
  const observer = new IntersectionObserver((entries) => {
    if (entries[0].isIntersecting) {
      loadGiscus()
      observer.disconnect()
    }
  })
  observer.observe(document.getElementById('giscus-comments'))
}
```

### 5.2 条件显示

只在文章页显示评论，首页、标签页不显示：

```vue
<template #doc-after>
  <GiscusComment v-if="isArticlePage" />
</template>

<script setup>
import { useData } from 'vitepress'
const { page } = useData()
const isArticlePage = computed(() =>
  page.value.filePath?.startsWith('posts/') || 
  page.value.filePath?.startsWith('guide/')
)
</script>
```

### 5.3 冷静期设置

设置评论频率限制，防止刷屏。Waline 内置了频率限制，Giscus 依赖 GitHub API 限流（每分钟 60 次）。

## 总结

| 场景 | 推荐方案 |
|------|---------|
| 读者主要是开发者 | **Giscus**（GitHub 账号门槛低） |
| 读者是普通用户 | **Waline**（支持匿名） |
| 要功能丰富 | **Waline**（邮件通知、表情、审核） |
| 要零维护 | **Giscus**（数据存 GitHub，无需后端） |
| 国内用户为主 | **Twikoo**（国内 CDN 友好） |
