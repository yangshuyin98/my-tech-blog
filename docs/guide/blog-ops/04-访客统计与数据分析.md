# 访客统计与数据分析

知道有多少人看了你的博客、他们从哪里来、看了哪些文章——这些数据对内容创作很有价值。

本文介绍三种主流的统计方案，你可以根据自己的需求选择。

---

## 方案对比

| 方案 | 部署难度 | 成本 | 隐私友好 | 功能 |
|------|---------|------|---------|------|
| **Umami** | 中等 | 免费自建 / ¥99/月托管 | ✅✅ 完全匿名 | 基础分析 |
| **Plausible** | 中等 | 免费自建 / €9/月 | ✅✅ 完全匿名 | 简洁清晰 |
| **百度统计** | 低 | 免费 | ❌ 需 Cookie | 国内用户行为 |
| **Google Analytics** | 低 | 免费 | ❌ 需 Cookie | 功能最全 |
| **不蒜子** | 最低 | 免费 | ✅ 轻量 | 仅统计 PV/UV |

**我的推荐：Umami + 百度统计 双线并行**——Umami 做核心分析，百度统计补国内数据。

---

## 1. Umami 自建统计

[Umami](https://umami.is/) 是一款开源、轻量、隐私友好的网站统计工具，数据完全掌控在自己手中。

### 1.1 使用 Umami Cloud（推荐）

最快的方式是用 Umami 官方托管服务：

1. 访问 [umami.is](https://umami.is) 注册
2. 添加网站：
   - Name: `我的博客`
   - Domain: `你的域名.com`
3. 获取跟踪代码

### 1.2 自建部署（完全控制）

#### 用 Vercel + Supabase 一键部署

1. 克隆项目：
```bash
git clone https://github.com/umami-software/umami.git
cd umami
```

2. 创建 Supabase 项目（免费版足够）
3. 在 Vercel 中导入仓库
4. 配置环境变量

#### 用 Docker 部署

```yaml
# docker-compose.yml
version: '3'
services:
  umami:
    image: ghcr.io/umami-software/umami:postgresql-latest
    ports:
      - "3000:3000"
    environment:
      DATABASE_URL: postgresql://user:password@db:5432/umami
      DATABASE_TYPE: postgresql
      APP_SECRET: 替换为随机字符串
    depends_on:
      - db
  db:
    image: postgres:15-alpine
    environment:
      POSTGRES_DB: umami
      POSTGRES_USER: user
      POSTGRES_PASSWORD: password
    volumes:
      - umami-db:/var/lib/postgresql/data

volumes:
  umami-db:
```

### 1.3 在博客中集成

在 `.vitepress/config.mts` 中添加跟踪脚本：

```typescript
head: [
  ['script', {
    defer: true,
    'data-website-id': '你的网站ID',
    src: 'https://你的umami实例.com/script.js',
  }],
],
```

### 1.4 Umami 能看什么

- **实时访客**：当前在线人数
- **页面浏览量 (PV)**：各文章访问排行
- **独立访客 (UV)**：去重后的访客数
- **来源渠道**：搜索引擎、社交媒体、直接访问
- **设备分布**：桌面端 / 移动端占比
- **访客地域**：城市级别的地理分布
- **跳出率**：只看了一页就离开的比例

## 2. Plausible 统计

[Plausible](https://plausible.io/) 和 Umami 定位类似，主打极致简洁。

### 2.1 集成

```typescript
head: [
  ['script', {
    defer: true,
    'data-domain': '你的域名.com',
    src: 'https://plausible.io/js/script.js',
  }],
],
```

### 2.2 事件跟踪

统计文章内的特定交互（如点击"点赞"按钮）：

```html
<button onclick="plausible('Like')">👍 点赞</button>
```

统计文件下载：

```html
<a href="/files/ebook.pdf" onclick="plausible('Download')">下载电子书</a>
```

## 3. 百度统计

如果你的读者主要在国内，百度统计不可或缺。它能帮你了解：

- 访客搜索了什么关键词找到你的博客
- 访客在哪些页面停留最久
- 页面加载速度

### 3.1 注册与集成

1. 访问 [tongji.baidu.com](https://tongji.baidu.com) 注册
2. 添加网站域名
3. 获取跟踪代码（一段 JavaScript）

在 `config.mts` 中集成：

```typescript
head: [
  ['script', {},
    `
    var _hmt = _hmt || [];
    (function() {
      var hm = document.createElement("script");
      hm.src = "https://hm.baidu.com/hm.js?你的HM编码";
      var s = document.getElementsByTagName("script")[0];
      s.parentNode.insertBefore(hm, s);
    })();
    `
  ],
],
```

### 3.2 百度统计能看什么

- **搜索词分析**：用户搜什么关键词进来的
- **受访页面**：每篇文章的浏览时长、跳出率
- **访客画像**：地域、设备、网络、年龄（需启用）
- **页面点击图**：热力图，看用户点哪里
- **转化路径**：用户从首页到文章的浏览路径

## 4. 不蒜子（极简方案）

如果你不想用任何第三方服务，只想知道"这个页面被看了多少次"，用不蒜子最合适。

### 4.1 集成

```typescript
head: [
  ['script', {
    async: true,
    src: 'https://busuanzi.ibruce.info/busuanzi/2.3/busuanzi.pure.mini.js',
  }],
],
```

### 4.2 在页面中显示

```html
<!-- 全站访问量 -->
<span id="busuanzi_value_site_pv"></span> 次访问

<!-- 全站访客数 -->
<span id="busuanzi_value_site_uv"></span> 位访客

<!-- 本页阅读量 -->
<span id="busuanzi_value_page_pv"></span> 次阅读
```

在主题中加入自定义显示组件：

```vue
<template>
  <div class="page-stats">
    本页阅读 <span id="busuanzi_value_page_pv"></span> 次 ·
    全站访问 <span id="busuanzi_value_site_pv"></span> 次
  </div>
</template>

<script setup>
import { onMounted } from 'vue'

onMounted(() => {
  // 手动触发不蒜子更新
  if (window.busuanzi) {
    window.busuanzi?.fetch?.()
  }
})
</script>
```

## 5. 数据显示在页面上

在文章底部或页脚展示统计信息。以 Umami 为例，创建一个统计面板组件：

```vue
<template>
  <div class="umami-stats" v-if="stats">
    <div class="stat-item">
      <span class="stat-value">{{ stats.pageviews }}</span>
      <span class="stat-label">阅读</span>
    </div>
    <div class="stat-item">
      <span class="stat-value">{{ stats.visitors }}</span>
      <span class="stat-label">访客</span>
    </div>
  </div>
</template>

<script setup>
import { ref, onMounted } from 'vue'
import { useData } from 'vitepress'

const { page } = useData()
const stats = ref(null)

async function fetchStats() {
  try {
    const res = await fetch(`https://你的umami-api.com/api/websites/网站ID/pageviews`, {
      headers: { 'x-api-key': '你的API密钥' },
    })
    const data = await res.json()
    stats.value = data
  } catch {
    // 静默失败，不影响页面渲染
  }
}

onMounted(fetchStats)
</script>
```

> ⚠️ 注意：暴露 API 密钥有安全风险。建议通过 Cloudflare Workers 等代理请求。

## 6. 数据驱动内容创作

有了数据之后，可以做这些事：

### 6.1 发现热门内容

```
查看 Umami → 页面排行 → 找出 Top 10 文章
→ 分析它们为什么受欢迎（主题、标题、发布时间）
→ 写同类文章
```

### 6.2 发现流失内容

```
查看跳出率 > 80% 的文章
→ 内容质量不够？标题党？
→ 更新内容或修改标题
```

### 6.3 发现搜索需求

```
百度统计 → 搜索词报告
→ 访客搜了什么词找到你的？
→ 围绕这些词写更多深度文章
```

## 总结

| 阶段 | 推荐方案 |
|------|---------|
| 刚开博客，只想看看有没有人 | **不蒜子** — 1 行代码搞定 PV/UV |
| 想了解访客来源和行为 | **Umami** — 自建免费，隐私友好 |
| 国内访客为主 | **百度统计** — 了解搜索来源 |
| 追求极致简洁 | **Plausible** — 颜值最高 |
| 全都要 | **Umami + 百度统计** — 双线并行 |
