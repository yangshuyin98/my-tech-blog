# ④ 编写文章与首页

## 文章存放位置

博客文章存放在 `docs/posts/` 目录下，支持 Markdown 语法。

```
docs/posts/
├── 1.md
├── 2.md
└── ...
```

你可以在 `posts/` 中创建子目录组织文章：

```
docs/posts/
├── frontend/
│   ├── vue-guide.md
│   └── react-vs-vue.md
├── backend/
│   └── nodejs-intro.md
└── ...
```

## 文章 Frontmatter

每篇文章开头使用 YAML frontmatter 定义元数据：

```yaml
---
title: 文章标题
description: 文章描述（会显示在搜索结果和分享卡片中）
date: 2026-05-11
tags:
  - VitePress
  - 博客
categories: 前端
cover: /cover.jpg       # 封面图（可选）
author: 杨树银            # 作者（可选，覆盖默认）
top: true                # 置顶（可选）
sticky: 1                # 排序权重（可选，越大越靠前）
hiddenCover: false       # 是否隐藏封面（可选）
---
```

### 常用 Frontmatter 字段

| 字段 | 说明 | 是否必填 |
|------|------|---------|
| `title` | 文章标题 | ✅ |
| `description` | 文章描述 | 推荐 |
| `date` | 发布日期 | 推荐 |
| `tags` | 标签（数组） | 可选 |
| `categories` | 分类（字符串或数组） | 可选 |
| `cover` | 封面图路径 | 可选 |
| `top` | 是否置顶 | 可选 |
| `sticky` | 排序权重 | 可选 |

### 示例文章

```markdown
---
title: 我的第一篇博客文章
description: 用 sugar-blog 写的第一篇文章
date: 2026-05-11

cover: /logo.png
---

# 我的第一篇博客文章

欢迎来到我的博客！这是我的第一篇文章。

## 首页配置

首页是 `docs/index.md`，sugar-blog 有默认的博客首页布局，你只需要写少量内容：

```markdown
---
# 首页默认使用博客布局，不需要额外配置
---

<!-- 首页内容会被展示在文章列表上方 -->
欢迎来到我的博客 🎉
```

### 首页博客列表

sugar-blog 会自动将 `docs/posts/` 中的文章按日期倒序排列展示在首页。文章列表展示：

- 文章标题
- 发布日期
- 文章摘要（取 frontmatter 的 description）
- 标签
- 封面图

## 内置 Markdown 扩展

sugar-blog 继承了 VitePress 的 Markdown 扩展能力：

### 提示框

```markdown
::: tip 提示
这是一个提示
:::

::: warning 注意
这是一个警告
:::

::: danger 危险
这是一个危险提示
:::

::: info 信息
这是一个信息框
:::

::: details 点击展开详情
这里是折叠内容
:::
```

### 代码块

支持行高亮和文件名：

````markdown
```typescript{2,4-6}
// 高亮第2行和4-6行
const name: string = 'sugar-blog'
const version = '0.5.19'
const features = [
  '搜索', '评论', 'RSS'
]
```
````

### 自定义容器

```markdown
::: center
居中的内容
:::

::: right
右对齐的内容
:::
```

## 文章标签与分类

sugar-blog 会自动根据文章 frontmatter 中的 `tags` 和 `categories` 生成标签页和分类页。

在首页的「标签」区域可以看到所有标签，点击可筛选文章。

::: tip 技巧
给文章打上合适的标签，能帮助读者快速找到相关内容。
:::

## 归档页面

sugar-blog 内置了归档页面，访问 `/archives` 即可查看文章时间线。
