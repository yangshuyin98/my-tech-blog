# ⑤ 个性化定制

## 主题色修改

sugar-blog 内置了多套主题色，在 `blog-theme.ts` 中配置：

```typescript
themeColor: 'el-blue',     // 蓝色系（默认）
```

### 内置主题色一览

| 值 | 效果 |
|------|------|
| `el-blue` | 清爽蓝色（默认） |
| `#e74c3c` | 热情红色 |
| `#2ecc71` | 自然绿色 |
| `#9b59b6` | 神秘紫色 |
| `#f39c12` | 温暖橙色 |
| 任何十六进制色值 | 完全自定义 |

### 自由设置色值

```typescript
themeColor: '#FF6B6B',  // 珊瑚粉
```

## Logo 与 Favicon

### 网站 Logo

将 logo 图片放在 `docs/public/` 目录，然后在 `config.mts` 中配置：

```typescript
themeConfig: {
  logo: '/logo.png',
}
```

### Favicon

```typescript
head: [
  ['link', { rel: 'icon', href: '/favicon.ico' }]
]
```

注意：如果 `base` 路径修改了，favicon 路径也要同步修改：

```typescript
const base = '/my-tech-blog/'
head: [
  ['link', { rel: 'icon', href: `${base}favicon.ico` }]
]
```

如果不显示页脚内容，注释掉对应的字段即可。

## 公告弹窗

公告弹窗在 `blog-theme.ts` 中配置：

```typescript
popover: {
  title: '公告',
  body: [
    { type: 'text', content: '👇 欢迎关注 👇' },
    { 
      type: 'image', 
      src: '/weixin.png', 
      alt: '微信二维码' 
    },
    { 
      type: 'button', 
      content: '加群交流',
      props: { type: 'success' },
      link: '#',
    }
  ],
  // duration: 0 表示不自动关闭
  // 设置具体毫秒数可以自动关闭
  duration: 0,
}
```

### body 支持的内容类型

| type | 用途 | 额外属性 |
|------|------|---------|
| `text` | 文本内容 | `content`, `style` |
| `image` | 图片 | `src`, `alt` |
| `button` | 按钮 | `content`, `link`, `props.type` |
| `html` | 自定义 HTML | `content` |

## 自定义 CSS

如果需要更精细的样式定制，可以在 `docs/.vitepress/theme/` 中添加 CSS：

```css
/* docs/.vitepress/theme/custom.css */

/* 修改文章标题颜色 */
.vp-doc h1 {
  color: #2c3e50;
  font-size: 2rem;
}

/* 自定义引用样式 */
.vp-doc blockquote {
  border-left-color: #42b983;
  background: #f0faf4;
}
```

然后在主题入口文件中引入：

```typescript
// docs/.vitepress/theme/index.ts
import DefaultTheme from 'vitepress/theme'
import './custom.css'

export default DefaultTheme
```

## 文章封面

在文章 frontmatter 中设置封面图：

```yaml
---
title: 文章标题
cover: /logo.png           # 封面图（放在 docs/public/ 中）
hiddenCover: false          # 是否隐藏封面
---
```
