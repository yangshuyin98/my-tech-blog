# ① 项目初始化

## 创建项目

sugar-blog 提供了官方模板，一行命令即可创建项目：

```bash
pnpm create @sugarat/theme my-tech-blog
```

命令执行后会询问是否安装依赖，选择 **Yes** 即可自动完成 pnpm install。

::: tip
如果选择 No，后续可以手动执行 `pnpm install` 安装依赖。
:::

## 目录结构

创建完成后，项目的核心目录结构如下：

```
my-tech-blog/
├── docs/                    # 📁 文档目录（博客内容）
│   ├── .vitepress/          #   ├── 配置文件目录
│   │   ├── config.mts       #   │   ├── VitePress 配置文件
│   │   ├── blog-theme.ts    #   │   ├── sugar-blog 主题配置
│   │   └── theme/           #   │   └── 自定义主题样式
│   ├── public/              #   ├── 静态资源（图片、favicon等）
│   ├── posts/               #   ├── 📝 博客文章目录
│   ├── index.md             #   ├── 🏠 首页
│   ├── about.md             #   ├── 关于页面
│   └── archives.md          #   └── 归档页面
├── package.json
├── tsconfig.json
└── pnpm-lock.yaml
```

### 关键文件说明

| 文件/目录 | 作用 |
|-----------|------|
| `docs/.vitepress/config.mts` | VitePress 核心配置（导航、侧边栏、base 路径等） |
| `docs/.vitepress/blog-theme.ts` | sugar-blog 主题专属配置（作者、评论、搜索等） |
| `docs/posts/` | 存放博客文章，支持 Markdown 语法 |
| `docs/public/` | 静态资源目录，里面的文件会原样复制到构建输出 |
| `docs/index.md` | 网站首页 |

## 安装依赖

查看 `package.json` 确认依赖已安装：

```json
{
  "dependencies": {
    "@sugarat/theme": "^0.5.19"
  },
  "devDependencies": {
    "vitepress": "2.0.0-alpha.17",
    "typescript": "^5.4.5"
  }
}
```

核心依赖只有两个：
- **@sugarat/theme** — 博客主题（已包含 VitePress 所需功能）
- **vitepress** — 构建框架

## 启动开发服务器

```bash
pnpm dev
```

![启动成功](https://img.cdn.sugarat.top/mdImg/MTY3NDk5NTE2NzAzMA==674995167030)

默认访问 `http://localhost:5173`，可以看到默认的博客首页。

## 常用命令

| 命令 | 作用 |
|------|------|
| `pnpm dev` | 启动开发服务器（热更新） |
| `pnpm build` | 构建生产版本 |
| `pnpm serve` | 预览构建结果 |
| `pnpm docs:preview` | 预览构建结果（同上） |

## 验证项目可用

1. 运行 `pnpm dev` 确认开发服务器正常启动
2. 打开浏览器访问 `http://localhost:5173`
3. 修改 `docs/index.md` 看看页面是否热更新
