# ⑧ 踩坑记录与常见问题

本篇文章记录了搭建博客过程中遇到的实际问题和解决方案。

## 1. 部署问题

### 🐛 GitHub Actions 工作流不触发

**现象**：推送代码后，Actions 页面没有运行记录。

**原因**：`deploy.yml` 中的分支名不匹配。

**配置检查**：

```yaml
# 错误：仓库分支是 master，但配置了 main
on:
  push:
    branches: [main]

# 正确：与仓库默认分支一致
on:
  push:
    branches: [master]
```

**解决**：将分支名改为与仓库默认分支一致（常见的是 `main` 或 `master`）。

### 🐛 部署后页面空白

**现象**：访问 GitHub Pages 链接显示空白页。

**原因**：`base` 路径配置错误。

**本地开发**：`base: '/'`
**部署环境**：`base: '/仓库名/'`

**解决方案**：利用环境变量区分：

```typescript
const base = process.env.GITHUB_ACTIONS === 'true' 
  ? '/my-tech-blog'    // GitHub Actions 环境
  : '/'                 // 本地开发环境
```

### 🐛 资源 404（CSS/图片不加载）

**现象**：页面能访问但没有任何样式，或图片显示不出来。

**原因**：资源的引路径缺少 base 前缀。

**解决**：所有在 `config.mts` 的 `head` 中引用的资源，需要加上 base 前缀：

```typescript
head: [
  ['link', { rel: 'icon', href: `${base}favicon.ico` }]
]
```

## 2. 构建问题

### 🐛 TypeScript 编译报错

**现象**：运行 `pnpm build` 时提示 TypeScript 类型错误：

```
Type 'xxx' is not assignable to type 'xxx'
```

**解决**：检查 `tsconfig.json` 配置：

```json
{
  "compilerOptions": {
    "moduleResolution": "bundler",
    "target": "ES2022",
    "module": "ESNext",
    "strict": true,
    "esModuleInterop": true,
    "skipLibCheck": true
  },
  "include": ["docs/.vitepress/**/*"]
}
```

关键点：`"skipLibCheck": true` 跳过库文件的类型检查。

### 🐛 构建成功但文章没显示

**现象**：首页没有显示文章列表。

**原因**：文章没有放在 `docs/posts/` 目录，或 frontmatter 缺失。

**解决**：确认文章在 `docs/posts/` 目录下，并且包含基本的 frontmatter：

```yaml
---
title: 文章标题
date: 2026-05-11
---
```

## 3. 评论系统问题

### 🐛 Giscus 评论不显示

**现象**：文章底部没有评论框。

**原因**：以下任一原因都会导致评论不显示。

**排查步骤**：

1. **检查仓库是否启用了 Discussions**
   - 仓库 → Settings → 确认 Discussions 已勾选

2. **检查 Giscus App 是否安装**
   - 访问 `https://github.com/settings/installations` 确认已安装

3. **检查配置是否正确**
   ```typescript
   comment: {
     type: 'giscus',
     options: {
       repo: 'yangshuyin98/my-tech-blog',    // 格式：用户名/仓库名
       repoId: 'R_kgDOSaDZJw',               // 从 giscus.app 获取
       category: 'Announcements',
       categoryId: 'DIC_kwDOSaDZJ84C8xHF',   // 从 giscus.app 获取
     }
   }
   ```

4. **确认仓库名格式正确**
   - ❌ `my-tech-blog`（缺少用户名）
   - ✅ `yangshuyin98/my-tech-blog`

## 4. 搜索问题

### 🐛 搜索框不显示

**现象**：首页没有搜索按钮。

**原因**：未安装 Pagefind。

**解决**：

```bash
pnpm add -D pagefind
```

### 🐛 搜索没有结果

**现象**：搜索框显示但搜不到内容。

**原因**：Pagefind 索引构建失败。

**解决**：删除 `docs/.vitepress/cache/` 目录后重新构建：

```bash
rm -rf docs/.vitepress/cache
pnpm build
```

## 5. 本地开发问题

### 🐛 热更新不生效

**现象**：修改文章后页面没有自动刷新。

**解决**：检查文件路径是否正确，确认文件在 `docs/` 目录下。

### 🐛 端口被占用

**现象**：启动开发服务器时提示端口被占用。

**解决**：指定其他端口：

```bash
pnpm dev --port 3000
```

## 6. 路径与链接问题

### 🐛 导航链接 404

**现象**：点击导航栏链接跳转到 404 页面。

**原因**：链接路径与文件路径不匹配。

**路径规则**：

| 文件位置 | 链接写法 |
|---------|---------|
| `docs/about.md` | `/about` |
| `docs/guide/xxx.md` | `/guide/xxx` |
| `docs/posts/xxx.md` | `/posts/xxx` |

注意：**不需要**写 `.md` 后缀。

### 🐛 侧边栏不显示

**现象**：进入 `/guide/` 下的页面时侧边栏为空。

**原因**：侧边栏配置中缺少对应的路径分组。

**解决**：

```typescript
sidebar: {
  '/guide/': [    // 访问 /guide/ 下页面时使用这个侧边栏
    {
      text: '教程',
      items: [ /* ... */ ]
    }
  ],
}
```

## 快速排查清单

遇到问题时按以下顺序排查：

| # | 检查项 | 命令/位置 |
|---|--------|----------|
| 1 | 本地能否正常构建 | `pnpm build` |
| 2 | 分支名是否正确 | `.github/workflows/deploy.yml` |
| 3 | base 路径是否正确 | `config.mts` 中的 `base` |
| 4 | 资源路径是否有 base 前缀 | `config.mts` 中的 `head` 配置 |
| 5 | 文章是否在 `posts/` 目录 | `docs/posts/` |
| 6 | frontmatter 是否完整 | 文章开头 YAML 部分 |
| 7 | Giscus 配置是否正确 | `blog-theme.ts` 中的 `comment` |
| 8 | Pagefind 是否安装 | `package.json` 中的 `pagefind` |
