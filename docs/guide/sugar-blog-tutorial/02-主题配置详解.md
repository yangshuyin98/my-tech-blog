# ② 主题配置详解

sugar-blog 的主题配置集中在 `docs/.vitepress/blog-theme.ts` 文件中。这个文件通过 `getThemeConfig()` 函数生成主题配置，然后导出给 `config.mts` 使用。

## 基础配置

### 作者信息

```typescript
const blogTheme = getThemeConfig({
  author: '杨树银',
})
```

文章默认显示的作者名，也可以在文章 frontmatter 中单独覆盖。

### 推荐阅读

控制文章底部推荐模块的显示样式：

```typescript
recommend: {
  title: '📌 推荐阅读',     // 推荐模块标题
  nextText: '下一组',        // 切换按钮文案
  pageSize: 5,               // 每次显示数量
  style: 'card',             // 样式: 'card' | 'sidebar' | undefined
}
```

- `card`：卡片样式，更醒目
- `sidebar`：侧边栏样式，更紧凑
- `undefined`：不显示

### 精选文章

首页右侧的精选文章模块：

```typescript
hotArticle: {
  title: '🔥 精选文章',
  nextText: '换一组',
  pageSize: 9,               // 显示文章数量
}
```

精选文章的内容来自 tag 为 `hot` 的文章。

### 首页标签

```typescript
homeTags: {
  title: '🏷 标签',
  limit: 20,                 // 标签显示数量，超出折叠
  showCount: true,           // 显示每篇文章数量
  sort: 'desc',              // 排序方式：desc | asc
}
```

## 文章配置

```typescript
article: {
  readingTime: true,          // 显示预计阅读时间
  hiddenCover: false,         // 是否默认隐藏封面
}
```

- `readingTime`：在文章头部显示预计阅读时长
- `hiddenCover`：控制封面图的显示

## RSS 支持

```typescript
const baseUrl = 'https://yangshuyin98.github.io/my-tech-blog'
const RSS = {
  title: 'shuyin的技术博客',
  baseUrl,
  copyright: 'Copyright (c) 2026-present, shuyin',
  description: 'shuyin的技术博客，记录前端学习与实践',
  language: 'zh-cn',
  image: '/logo.png',
  favicon: '/favicon.ico',
}
```

开启 RSS 后，访问 `/rss.xml` 即可看到订阅源。

## 搜索功能

sugar-blog 使用 Pagefind 实现离线全文搜索：

```typescript
search: {
  btnPlaceholder: '搜索',
  placeholder: '搜索文章...',
  emptyText: '没有找到相关内容',
  heading: '共 {{searchResult}} 条搜索结果',
}
```

::: tip
需要安装 pagefind 依赖：

```bash
pnpm add -D pagefind
```
:::

## 评论系统

sugar-blog 支持多种评论方案，推荐使用 Giscus（基于 GitHub Discussions）：

```typescript
comment: {
  type: 'giscus',
  options: {
    repo: 'yangshuyin98/my-tech-blog',
    repoId: 'R_kgDOSaDZJw',
    category: 'Announcements',
    categoryId: 'DIC_kwDOSaDZJ84C8xHF',
  }
}
```

### 获取 Giscus 配置

1. 在 GitHub 上安装 [Giscus App](https://github.com/apps/giscus)
2. 进入仓库 → Settings → Discussions，**启用 Discussions**
3. 访问 [giscus.app](https://giscus.app)，填写仓库名获取配置
4. 将生成的 `repoId`、`categoryId` 填入配置

## 主题色

```typescript
themeColor: 'el-blue',
```

sugar-blog 内置了多套主题色：

| 主题色 | 效果 |
|--------|------|
| `el-blue` | 蓝色（默认） |
| `#ff6b6b` | 珊瑚红 |
| `#2ecc71` | 翡翠绿 |
| `#9b59b6` | 紫色 |
| 自定义色值 | 任意颜色代码 |

## 公告弹窗

```typescript
popover: {
  title: '公告',
  body: [
    { type: 'text', content: '👇公众号👇---👇 微信 👇' },
    { type: 'image', src: '/weixin.png', alt: '微信二维码' },
    { type: 'button', content: '作者博客', link: '#' },
  ],
  duration: 0,  // 0 表示不自动关闭
}
```

支持多种内容类型：`text`（文本）、`image`（图片）、`button`（按钮）。
